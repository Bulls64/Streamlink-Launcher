# Code of conduct · Code de conduite

## English

This project is a small, friendly open-source project. Everyone is welcome to report a bug, suggest an idea or send a pull request, whatever their level or background.

**Expected behavior**
- Be respectful and patient. Criticize the code or the idea, never the person.
- Stay on topic and give useful details (version, steps to reproduce, logs without tokens).
- Accept that the maintainer decides what goes into the project and may say no.

**Not accepted**
- Insults, harassment, discrimination or personal attacks.
- Publishing someone's private information, or your own tokens and secrets, in an issue or a pull request.
- Spam, advertising and off-topic content.

**Enforcement.** The maintainer may edit, hide or delete comments, issues and pull requests that break these rules, and block repeat offenders. To report a problem, use the private form in the [security policy](SECURITY.md) (*Report a vulnerability*) or contact the maintainer through his [GitHub profile](https://github.com/Bulls64).

## Français

Ce projet est un petit projet libre et bienveillant. Chacun est le bienvenu pour signaler un bug, proposer une idée ou envoyer une pull request, quel que soit son niveau ou son parcours.

**Comportement attendu**
- Soyez respectueux et patient. Critiquez le code ou l'idée, jamais la personne.
- Restez dans le sujet et donnez des détails utiles (version, étapes pour reproduire, journal sans jetons).
- Acceptez que le mainteneur décide de ce qui entre dans le projet et puisse refuser.

**Non accepté**
- Insultes, harcèlement, discrimination ou attaques personnelles.
- Publier des informations privées d'autrui, ou vos propres jetons et secrets, dans un ticket ou une pull request.
- Spam, publicité et contenus hors sujet.

**Application.** Le mainteneur peut modifier, masquer ou supprimer les commentaires, tickets et pull requests qui enfreignent ces règles, et bloquer les récidivistes. Pour signaler un problème, utilisez le formulaire privé de la [politique de sécurité](SECURITY.md) (*Report a vulnerability*) ou contactez le mainteneur via son [profil GitHub](https://github.com/Bulls64).
