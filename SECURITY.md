# Security policy · Politique de sécurité

## English

**Supported versions.** Only the [latest release](https://github.com/Bulls64/Streamlink-Launcher/releases/latest) receives fixes.

**Reporting a vulnerability.** Please do **not** open a public issue. Use the private form:
[Report a vulnerability](https://github.com/Bulls64/Streamlink-Launcher/security/advisories/new)
(Security tab → *Report a vulnerability*). Include the version, the steps to reproduce and the impact.
You will get an answer within about a week.

**Good to know.**
- The executables are **not code-signed** (see the README). Check the SHA-256 given in `SHA256SUMS.txt` and in the release.
- The in-app updater only downloads from this repository's GitHub releases, checks the SHA-256 published by GitHub, and refuses a file whose signature is invalid.

## Français

**Versions prises en charge.** Seule la [dernière version](https://github.com/Bulls64/Streamlink-Launcher/releases/latest) reçoit des correctifs.

**Signaler une faille.** N'ouvrez **pas** de ticket public. Utilisez le formulaire privé :
[Signaler une vulnérabilité](https://github.com/Bulls64/Streamlink-Launcher/security/advisories/new)
(onglet Security → *Report a vulnerability*). Indiquez la version, les étapes pour reproduire et l'impact.
Réponse sous environ une semaine.

**À savoir.**
- Les exécutables ne sont **pas signés** (voir le README). Vérifiez l'empreinte SHA-256 de `SHA256SUMS.txt` et de la release.
- La mise à jour intégrée ne télécharge que depuis les releases GitHub de ce dépôt, vérifie le SHA-256 publié par GitHub et refuse un fichier dont la signature est invalide.
