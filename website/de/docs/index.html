01 · Überblick

Was sind Streamlink Launcher und Streamlink Chat?

Launcher

Eine schlanke Oberfläche für Streamlink. Gib einen Kanalnamen ein oder füge einen Link ein, drücke Enter, und der Stream öffnet sich in deinem Videoplayer (VLC, mpv, PotPlayer…) statt im Browser. Er merkt sich deine Favoriten, zeigt dir, wer davon live ist, und öffnet mit Strg+Alt+S eine Mini-Leiste.

Chat

Der Begleiter des Launchers, im Stil von Chatterino: die Chats von Twitch, Kick und Steam TV in einem Fenster, ein Tab pro Chat, jeder in der Farbe seiner Plattform. Lesen ohne Konto, Schreiben auf Twitch und Kick nach der Anmeldung, und ▶ öffnet den Stream mit Streamlink.

Unterstützte Plattformen

KickJaLesen und Schreiben (experimentell)
Steam TVJaNur lesen
YouTube, DailymotionJaNein
DirektlinkJede von Streamlink unterstützte WebsiteNein

Systemvoraussetzungen

  • Windows 10 oder 11: eine einzelne .exe-Datei, ohne Installation.
  • Linux x86_64: ein AppImage mit eigenem Python. Es braucht glibc 2.35 oder neuer (Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 oder neuer).
  • Aus dem Quellcode: Python 3.10 oder neuer mit Tcl/Tk, keine weitere Abhängigkeit.
  • Zum Ansehen: Streamlink und ein Videoplayer, standardmäßig VLC.

Unter Linux hat der Launcher kein Symbol im Infobereich, keine globale Tastenkombination, keinen Autostart, kein Drag-and-drop, keine Live-Benachrichtigungen, keine Stream-Vorschau und kein integriertes Update.

Sprachen

Beide Apps gibt es auf Englisch, Französisch, Spanisch, Deutsch und Italienisch. Sie folgen der Systemsprache; du kannst sie unter Einstellungen › Allgemein (Launcher) oder Einstellungen › Anzeige (Chat) ändern.

03 · Der Motor

Was ist Streamlink?

Streamlink ist ein freies Kommandozeilenprogramm. Es holt den Videostrom eines Streams und schickt ihn an deinen Player. So siehst du Twitch, Kick oder YouTube in VLC oder mpv, ohne die Webseite drumherum: weniger Arbeitsspeicher, keine Twitch-Werbung und die Tastenkürzel deines eigenen Players.

Normalerweise benutzt man Streamlink in einem Terminal:

$ streamlink https://www.twitch.tv/eslcs best

Streamlink Launcher schreibt diesen Befehl für dich: Er erkennt die Plattform, fügt die passenden Optionen und die gewählte Qualität hinzu und startet dann Streamlink. Streamlink Chat nutzt es für seine Schaltfläche ▶.

Qualitäten

best wählt die höchste Qualität, worst die niedrigste, audio_only nur den Ton (Twitch). Du kannst auch eine bestimmte Qualität wie 1080p60 anfordern oder eine Ausweichliste: 720p60,720p,best nimmt die erste verfügbare.

Und die Twitch-Werbung?

Seit Version 7.5.0 filtert Streamlink die Werbung in Twitch-Streams immer heraus. Die alte Option --twitch-disable-ads wird nicht mehr gebraucht (sie ist veraltet, wird aber weiterhin akzeptiert).

Streamlink ist ein unabhängiges Projekt. Keine der beiden Apps enthält es: Du installierst es separat, einmalig.

04 · Installation

Wo lädt man Streamlink herunter und wie installiert man es?

Streamlink gibt es auf seiner offiziellen Website, streamlink.github.io/install. Wähle dein System:

Windows: das Installationsprogramm (empfohlen)

  1. Öffne die Seite mit den Windows-Versionen von Streamlink.
  2. Lade das .exe-Installationsprogramm der neuesten Version herunter (Windows 10 oder neuer, x86_64).
  3. Starte es und folge den Schritten. Es fügt Streamlink dem PATH hinzu: Der Launcher findet es von selbst.

Oder mit einem Paketmanager

# winget (in Windows 11 enthalten) > winget install streamlink # Chocolatey > choco install streamlink # Scoop > scoop bucket add extras > scoop install streamlink

Linux: das Paket deiner Distribution

# Fedora $ sudo dnf install streamlink # Arch Linux $ sudo pacman -S streamlink # Debian testing / sid $ sudo apt update && sudo apt install streamlink

Ubuntu und Ableger: Die Streamlink-Website rät vom Ubuntu-Paket ab, da es nicht gepflegt wird. Nutze die Installation mit Python (nächster Tab) oder das Streamlink-AppImage, das auf derselben Seite angeboten wird.

Du brauchst außerdem einen Player, zum Beispiel sudo apt install mpv oder sudo dnf install vlc.

Mit Python (jedes System)

Erfordert Python 3.10 oder neuer.

$ pip install -U streamlink

Derselbe Befehl aktualisiert Streamlink. Unter Linux ist eine virtuelle Umgebung oder pipx install streamlink besser, damit das System-Python unangetastet bleibt.

Die Installation prüfen

$ streamlink --version

Wenn der Befehl eine Versionsnummer anzeigt, ist alles bereit. Im Launcher zeigt Einstellungen › Streamlink ebenfalls die gefundene Version.

Streamlink woanders installiert? Launcher Chat

Die Apps suchen Streamlink im PATH und an den üblichen Orten. Liegt es woanders, gib den Pfad zu streamlink.exe unter Einstellungen › Streamlink › Benutzerdefinierter Pfad (Launcher) oder Einstellungen › Ansehen (Chat) an.

05 · Loslegen

Erste Schritte

Wohin mit den Apps? Launcher Chat

Lade die Datei von der Versionsseite herunter (Launcher, Chat) und lege sie in einen eigenen Ordner, zum Beispiel Documents\Streamlink. Die Einstellungen werden daneben gespeichert, und das integrierte Update kann die Datei ersetzen. Meide C:\Program Files, das schreibgeschützt ist.

Unter Linux machst du das AppImage ausführbar und startest es dann:

$ chmod +x StreamlinkLauncher-*-x86_64.AppImage $ ./StreamlinkLauncher-*-x86_64.AppImage

Für einen Eintrag im Anwendungsmenü nutze ein Werkzeug wie Gear Lever oder AppImageLauncher.

Dein erster Stream Launcher

  1. Stelle sicher, dass Streamlink und ein Videoplayer installiert sind.
  2. Wähle die Plattform über ihre Schaltfläche: Twitch, Kick, YouTube, Dailymotion, Steam TV oder Direktlink.
  3. Gib den Kanalnamen ein (eslcs) oder füge einen Link ein (https://kick.com/…): Ein Link wählt die Plattform von selbst.
  4. Wähle bei Bedarf die Qualität, dann Enter oder Starten. Der Player öffnet sich nach ein paar Sekunden.
  5. Um den Stream zu verfolgen oder zu stoppen, öffne unten im Fenster das Protokoll: Es zeigt die Ausgabe von Streamlink und eine Schaltfläche Beenden.

Drei schnellere Wege Launcher

  • Einen Link kopieren: Kopiere die Adresse eines Streams und wechsle zurück zum Launcher. Er bietet an, ihn zu starten, und der Link steht schon in der Mini-Leiste. Abschaltbar unter Einstellungen › Streamlink › Kopierte Links erkennen.
  • Drag-and-drop (Windows): Ziehe die Adresse aus der Adressleiste des Browsers, einen markierten Text oder eine .url-Internetverknüpfung auf das Fenster.
  • Mini-Modus (Windows): Strg+Alt+S aus jeder Anwendung, tippen, Enter.

Dein erster Chat Chat

  1. Wähle die Plattform über ihre Schaltfläche unter dem Feld Chat hinzufügen.
  2. Gib den Kanalnamen ein oder füge einen Link ein, dann Enter. Strg+T setzt den Cursor in dieses Feld.
  3. Der Chat öffnet sich in einem neuen Tab, nur lesbar. Um zu schreiben, verbinde dein Konto (siehe Im Chat schreiben).
  4. In der Kopfzeile des Chats öffnet ▶ den Stream mit Streamlink, und das Link-Symbol öffnet den Kanal in deinem Browser.

Das Feld akzeptiert einen Namen (eslcs), ein Präfix (kick:lunaria, steam:name) oder einen Link: twitch.tv/…, kick.com/…, steam.tv/…, steamcommunity.com/broadcast/watch/…, „Popout“-Links eingeschlossen. Deine Tabs sind beim nächsten Start wieder da.

07 · Im Alltag

Wie verwalte ich Verlauf und Favoriten?

Einen Favoriten hinzufügen Launcher

  1. Wähle die Plattform über ihre Schaltfläche (Twitch, Kick…) und gib den Kanalnamen ein.
  2. Klicke auf dem Hauptbildschirm auf die Karte Favorit hinzufügen.

Der Hauptbildschirm zeigt die Favoriten der gewählten Plattform, die Live-Kanäle zuerst. Alle anzeigen öffnet die vollständige Liste.

Einen Favoriten starten, bearbeiten oder entfernen Launcher

  • Starten: Klicke auf seine Karte.
  • Weitere Optionen: Rechtsklick auf die Karte, dann Starten, Feld ausfüllen oder Aus Favoriten entfernen.
  • Im Bereich Favoriten: Ein Klick auf eine Zeile füllt das Feld aus, ▶ startet, der Papierkorb entfernt.

Wer ist live? Launcher

Mit Einstellungen › Live › Prüfen, wer live ist prüft der Launcher deine Twitch- und Kick-Favoriten, solange er geöffnet ist, alle 2, 5, 10, 15 oder 30 Minuten (standardmäßig 5). Live-Vorschau ergänzt Vorschaubild, Titel und Zuschauerzahl der Twitch-Favoriten, die live sind, und Windows-Benachrichtigung sagt dir Bescheid, wenn ein Favorit live geht: Klicke auf die Benachrichtigung, um zuzuschauen.

Verlauf Launcher

  • Die letzten 200 Starts werden gespeichert. Die neuesten erscheinen unter Zuletzt gesehen; ▶ startet sie direkt neu.
  • Gesamter Verlauf öffnet den Bereich: Ein Klick füllt das Feld aus, ▶ startet neu, der Papierkorb löscht einen Eintrag, Alles löschen leert den Verlauf.
  • Die Vorschläge im Eingabefeld kommen aus deinen Favoriten, dann aus deinem Verlauf: ↓ ↑, dann Enter.

Sichern oder auf einen anderen PC übertragen Launcher

Einstellungen › Sicherung › Exportieren… speichert deine Einstellungen und Favoriten in einer einzigen Datei. Importieren… stellt sie wieder her und lässt dich wählen: Ja fügt die importierten Favoriten zu deinen hinzu, Nein ersetzt deine Favoriten, Abbrechen ändert nichts. Rechnerspezifische Pfade (Streamlink, Player, Skripte) sind nicht enthalten, der Verlauf ebenfalls nicht.

Und im Chat? Chat

Streamlink Chat hat keine Favoriten: Geöffnete Chats sind beim nächsten Start von selbst wieder da. Schließe einen Chat mit Strg+W oder einem Mittelklick auf seinen Tab. Um immer dieselben Chats auf einmal zu öffnen, siehe das Rezept Deine Chats über eine Verknüpfung öffnen.

08 · Konten

Im Chat schreiben

Zum Lesen brauchst du kein Konto. Zum Schreiben brauchst du auf jeder Plattform eine eigene kostenlose Anwendung: So wird kein Geheimnis mit dem Programm ausgeliefert. Das machst du nur einmal.

Twitch verbinden Chat

  1. Öffne dev.twitch.tv/console/apps/create und melde dich mit deinem Twitch-Konto an. Twitch verlangt eventuell, dass du die Zwei-Faktor-Authentifizierung aktivierst, um die Konsole zu nutzen.
  2. Gib der Anwendung einen Namen, füge die Weiterleitungs-URL http://localhost hinzu, wähle die Kategorie Chat Bot und den Clienttyp Public und erstelle sie.
  3. Kopiere ihre Client ID und füge sie unter Einstellungen › Konten (zum Schreiben) ein.
  4. Klicke auf Bei Twitch anmelden. Eine Seite twitch.tv/activate öffnet sich: Gib den Code ein, den die App anzeigt, und autorisiere sie.
  5. Die Kopfzeile der Twitch-Chats wechselt zu Verbunden. Die Verbindung erneuert sich von selbst.

Die App fragt nur zwei Berechtigungen an: im Chat lesen und schreiben (chat:read, chat:edit).

Kick verbinden Chat

  1. Öffne die Entwicklereinstellungen von Kick und erstelle eine Anwendung.
  2. Trage die Weiterleitungs-URL http://localhost:48125/callback ein und aktiviere die Berechtigungen read user info und write to chat.
  3. Füge ihre Client ID und ihr Client Secret unter Einstellungen › Konten (zum Schreiben) ein.
  4. Klicke auf Bei Kick anmelden: Dein Browser öffnet Kick, autorisiere die Anwendung. Kick leitet dich zurück zu localhost:48125, wo die App auf die Antwort wartet.

Port 48125 muss frei sein, während du dich anmeldest. Nutzt ein anderes Programm ihn, schließe es für die Dauer der Anmeldung.

Steam TV Chat

Steam erlaubt es nicht, aus einem anderen Programm in den Chat einer Übertragung zu schreiben: Steam TV bleibt nur lesbar, ohne Konto.

Wo werden die Tokens gespeichert? Chat

  • In chat.json. Unter Windows sind sie mit DPAPI verschlüsselt: Nur dein Windows-Konto auf diesem PC kann sie wieder lesen.
  • Unter Linux liegen sie unverschlüsselt in deinem Home-Ordner. Gib diese Datei nicht weiter.
  • Wenn du chat.json auf einen anderen PC kopierst, können die Tokens dort nicht gelesen werden: Melde dich erneut an.

Abmelden und Zugriff widerrufen Chat

  • Abmelden unter Einstellungen › Konten löscht die Tokens von deinem PC.
  • Um den Zugriff auch bei Twitch zu widerrufen, öffne auf Twitch Einstellungen › Verbindungen und trenne deine Anwendung.
  • Bei Kick löschst du die Anwendung in den Entwicklereinstellungen.

10 · Rezepte

Rezepte für mehr Tempo

Den Player für die Schaltfläche ▶ wählen Chat

Der Chat startet Streamlink ohne Player-Option, also nutzt Streamlink den aus seiner Konfigurationsdatei, standardmäßig VLC. Um zu mpv zu wechseln, lege diese Datei an (ohne Endung) und füge hinzu:

configplayer=mpv player-args=--force-window=immediate
SystemKonfigurationsdatei von Streamlink
Windows%APPDATA%\streamlink\config
Linux~/.config/streamlink/config

Ist mpv nicht im PATH, gib nach player= den vollständigen Pfad an. Der Launcher nutzt diese Datei ebenfalls, wenn Einstellungen › Videoplayer auf Standard (Streamlink-Einstellung) steht.

Mit weniger Verzögerung schauen

Streamlink hat einen Modus mit niedriger Latenz für Twitch und Kick. Am einfachsten schaltest du ihn nur für eine Plattform ein, mit einer Konfigurationsdatei für ihr Plugin neben der Datei config:

config.twitchtwitch-low-latency
config.kickkick-low-latency

Das funktioniert für beide Apps. Der Gewinn hängt vom Streamer ab, der die niedrige Latenz aktiviert haben muss; die Wiedergabe kann etwas öfter puffern.

Einen Stream beim Anschauen aufnehmen

In einem Terminal schreibt --record den Stream in eine Datei, während du zuschaust:

$ streamlink --record "{author}-{time:%Y%m%d-%H%M}.ts" https://www.twitch.tv/eslcs best

{author} wird zum Kanalnamen und {time:…} zu Datum und Uhrzeit. Öffne die .ts-Datei mit VLC oder mpv.

Launcher Um das aus dem Launcher heraus zu tun, füge in platforms.json eine eigene Plattform hinzu (der Link platforms.json bearbeiten unten in den Einstellungen), mit einem vollständigen Pfad zu deinem Videoordner:

platforms.json (ein weiterer Eintrag in der Liste "platforms"){ "id": "twitch-rec", "name": "Twitch REC", "input": "channel", "url": "https://www.twitch.tv/{arg}", "hosts": [], "args": ["--record", "C:\\Users\\du\\Videos\\{author}-{time:%Y%m%d-%H%M}.ts"], "qualities": ["best", "1080p60", "720p60", "480p"], "color": "#E91916", "text_color": "#FFFFFF", "live_check": "none" }

Starte den Launcher neu: Eine Schaltfläche Twitch REC erscheint. hosts bleibt leer, damit eingefügte Twitch-Links weiter bei der normalen Twitch-Schaltfläche landen. In JSON wird jedes \ eines Windows-Pfads als \\ geschrieben.

Nie wieder „Qualität nicht gefunden“

Nicht jeder Kanal bietet jede Qualität an. Launcher Wähle in der Qualitätsliste Benutzerdefiniert… und gib eine Ausweichliste wie 720p60,720p,best ein: Streamlink nimmt die erste vorhandene, und der Launcher merkt sie sich für diese Plattform. Chat Die Qualität der Schaltfläche ▶ wird aus einer festen Liste gewählt; behalte best, wenn du sehr unterschiedliche Kanäle schaust.

Deine Chats über eine Verknüpfung öffnen Chat

Streamlink Chat akzeptiert Chats als Argumente. Erstelle eine Windows-Verknüpfung (Rechtsklick auf den Desktop › Neu › Verknüpfung) mit einem Ziel wie:

"C:\Users\du\Documents\Streamlink\StreamlinkChat.exe" --open twitch:eslcs --open kick:lunaria

Ist der Chat schon geöffnet, werden diese Chats dem bestehenden Fenster hinzugefügt. Ein Kanal-Link funktioniert ebenfalls als Argument.

Tipp: Benenne die ausführbare Datei zuerst ohne Versionsnummer um, zum Beispiel StreamlinkChat.exe. Eine Datei, die nach ihrer Version benannt ist, ändert bei jedem Update ihren Namen, und die Verknüpfung würde sie nicht mehr finden. Ein Name ohne Version bleibt erhalten.

Den Launcher minimiert starten Launcher

Einstellungen › Fenster und Tastenkombination › Mit Windows starten startet ihn im Infobereich. Dasselbe erreichst du mit deiner eigenen Verknüpfung, indem du --tray hinter den Pfad der ausführbaren Datei setzt.

Deine alten .bat-Skripte behalten Launcher

Wenn du deine Streams früher mit Skripten gestartet hast, aktiviere Einstellungen › Erweitert › .bat-Skripte anzeigen und wähle den Skriptordner. Eine Schaltfläche Skripte listet die Dateien .bat, .cmd, .ps1, .exe, .py und .lnk in diesem Ordner auf. Über das Feld kannst du dem Skript ein Argument übergeben (nur Buchstaben, Ziffern, ., _ und -).

11 · Updates

Wie aktualisiere ich die App?

Der Launcher Launcher

  1. Öffne Einstellungen › Über: Die Karte zeigt deine Version und die neueste auf GitHub veröffentlichte.
  2. Gibt es eine neuere Version, klicke auf Aktualisieren. Der Launcher lädt die neue .exe herunter, prüft ihre Größe und ihren SHA-256-Fingerabdruck, ersetzt die alte damit und startet neu.
  • Beim Start nach Updates suchen übernimmt die Prüfung von selbst.
  • Launcher automatisch aktualisieren installiert die neue Version zusätzlich beim Start, nie während eines Streams.
  • Eine Datei, die nach ihrer Version benannt ist (StreamlinkLauncher-1.4.2.exe), übernimmt die neue Nummer; der Autostart folgt dem neuen Namen.

Der Chat Chat

Gleiches Prinzip unter Einstellungen › Updates: Prüfen, dann Aktualisieren. Der Chat startet mit deinen geöffneten Chats neu. Ein Punkt auf der Einstellungsschaltfläche weist auf eine neue Version hin, und Automatische Updates (standardmäßig aus) erledigt alles von selbst beim Start.

AppImage oder Quellcode: Das Update per Klick gilt nur für die Windows-.exe in einem beschreibbaren Ordner (nicht C:\Program Files). Beim AppImage öffnet Aktualisieren die Versionsseite: Lade das neue AppImage herunter und ersetze das alte. Aus dem Quellcode führst du git pull aus.

Streamlink selbst aktualisieren

Der Launcher vergleicht deine Streamlink-Version mit der neuesten veröffentlichten. Ist deine älter, bietet die Karte Einstellungen › Streamlink Aktualisieren an: Beim Windows-Installationsprogramm öffnet sie die Download-Seite, bei pip kopiert sie den Befehl pip install -U streamlink. Mit winget, Chocolatey, Scoop oder deiner Linux-Distribution nutzt du deren üblichen Update-Befehl (zum Beispiel winget upgrade streamlink).

Wie wähle ich meinen Videoplayer? Launcher

Einstellungen › Fenster und Tastenkombination: Schalte Globale Tastenkombination ein oder aus und wähle eine andere Kombination als Strg+Alt+S. Dort wird auch der Status der Tastenkombination angezeigt.

Kann der Launcher im Hintergrund weiterlaufen? Launcher

Ja: Mit In den Infobereich minimieren bleibt der Launcher beim Schließen des Fensters neben der Uhr, mit deinen Streams und der Live-Überwachung. Rechtsklick auf das Symbol, um das Fenster wieder zu öffnen, den Mini-Modus zu öffnen, einen Live-Favoriten zu starten oder Beenden. Mit Windows starten startet ihn minimiert.

Wie schalte ich die Erkennung kopierter Links aus? Launcher

Kann ich die Plattformfarben entfernen? Launcher Chat

Ja: Farben je Plattform unter Einstellungen › Allgemein (Launcher) oder Einstellungen › Anzeige (Chat).

Wie füge ich eine Plattform hinzu? Launcher

Der Link platforms.json bearbeiten unten im Einstellungsbereich öffnet die Datei. Jeder Eintrag enthält:

  • id und name: eine eindeutige Kennung und den Namen der Schaltfläche;
  • input: channel, youtube, video, url (beliebiger Link) oder none (keine Eingabe);
  • url: die Adressvorlage, in der {arg} durch deine Eingabe ersetzt wird;
  • hosts: die Domains, die diese Schaltfläche beim Einfügen eines Links auswählen;
  • args: zusätzliche Streamlink-Optionen;
  • qualities, color, text_color;
  • live_check: twitch, streamlink oder none.

Speichere und starte den Launcher neu, um die neue Schaltfläche zu sehen. Ein vollständiges Beispiel steht im Rezept Einen Stream aufnehmen.

Wie schreibe ich in einem Chat? Chat

Verbinde dein Twitch- oder Kick-Konto unter Einstellungen › Konten (zum Schreiben). Die Schritte stehen ausführlich unter Im Chat schreiben.

Welche Anzeigeoptionen bietet der Chat? Chat

Einstellungen › Anzeige: Sprache, Design, Textgröße, Uhrzeit der Nachrichten, Abzeichen, animierte Emotes, Farben je Plattform und Anzahl der pro Chat gespeicherten Nachrichten (500, 1000, 2000 oder 5000). Emotes schaltet BetterTTV, FrankerFaceZ und 7TV ein oder aus. Erwähnungen hebt Nachrichten hervor, die deinen Namen oder Wörter deiner Wahl enthalten, durch Kommas getrennt.

14 · Fehlerbehebung

Fehlerbehebung (FAQ)

„Streamlink nicht gefunden“ Launcher Chat

Installiere Streamlink (siehe Streamlink installieren) und starte die App neu. Ist es woanders installiert, gib in den Einstellungen den Pfad zu streamlink.exe an. Prüfe in einem Terminal, ob streamlink --version antwortet.

Der Stream startet nicht Launcher

Öffne unten im Fenster das Protokoll: Dort steht die Fehlermeldung von Streamlink. Die häufigsten Ursachen:

  • No playable streams found: Der Kanal ist offline oder der Name ist falsch geschrieben.
  • Die angeforderte Qualität gibt es für diesen Stream nicht: Wähle best oder eine Ausweichliste über Benutzerdefiniert….
  • Der Videoplayer wird nicht gefunden: Gib seinen Pfad unter Einstellungen › Videoplayer an.
Der Stream ruckelt oder bricht ab Launcher Chat

Versuche eine niedrigere Qualität (720p, 480p): Sie braucht weniger Bandbreite. Hast du die niedrige Latenz aktiviert, nimm sie wieder heraus. Die Meldungen im Protokoll zeigen, ob Streamlink auf Daten wartet.

Ton ist da, aber kein Bild Launcher

Prüfe, ob die gewählte Qualität nicht audio_only ist. Andernfalls aktualisiere deinen Player; bei mpv öffnet die Option --force-window=immediate das Fenster sofort.

Windows zeigt „Der Computer wurde durch Windows geschützt“ Launcher Chat

Die ausführbaren Dateien sind noch nicht signiert, daher warnt SmartScreen beim ersten Start. Das ist keine Erkennung.

  1. Prüfe die Datei: in PowerShell Get-FileHash .\StreamlinkLauncher-1.5.1.exe, und vergleiche mit der SHA256SUMS.txt der Version.
  2. Klicke auf Weitere Informationen, dann auf Trotzdem ausführen.
  3. Passiert beim Doppelklick nichts: Rechtsklick › Eigenschaften › Zulassen ankreuzen, oder Unblock-File .\StreamlinkLauncher-1.5.1.exe.
Mein Virenschutz blockiert oder löscht die exe Launcher Chat

Mit PyInstaller erstellte Programme werden manchmal irrtümlich gemeldet. Prüfe den SHA-256, stelle die Datei aus der Quarantäne wieder her, füge ihren Ordner zu den Ausnahmen hinzu und melde den Fehlalarm (Microsoft Defender: Datei einreichen, Kategorie Incorrectly detected as malware). Du kannst die App auch aus dem Quellcode starten.

Strg+Alt+S bewirkt nichts Launcher

Wahrscheinlich nutzt eine andere Anwendung diese Tastenkombination. Der Launcher warnt dich beim Start; wähle unter Einstellungen › Fenster und Tastenkombination eine andere. Jeder empfangene Tastendruck wird im Protokoll vermerkt. Die globale Tastenkombination gibt es nur unter Windows.

Die App öffnet sich kein zweites Mal Launcher Chat

Das ist so gewollt: Von jeder App läuft immer nur eine Instanz. Der Launcher ist wahrscheinlich im Infobereich neben der Uhr. Beim Chat schickt ein erneutes Öffnen seine Chats an das bereits geöffnete Fenster.

„Der Ordner des Launchers ist schreibgeschützt“ Launcher

Der Launcher kann nicht neben seine .exe schreiben (zum Beispiel in C:\Program Files). Er speichert seine Daten dann in %APPDATA%\Streamlink Launcher. Alles funktioniert, aber das integrierte Update kann die Datei nicht ersetzen: Verschiebe sie in einen eigenen Ordner.

Das AppImage startet nicht Launcher Chat
  • Mache es ausführbar: chmod +x gefolgt vom Dateinamen.
  • Meldung zu FUSE: Installiere libfuse2 oder starte es mit --appimage-extract-and-run.
  • Fehler zu GLIBC: Dein System ist zu alt (mindestens glibc 2.35). Starte die App aus dem Quellcode.
Ein Kick-Chat bleibt im Fehlerzustand Chat

Kick hat sein Chatsystem am 13. Oktober 2026 geändert und dokumentiert es nicht: Die Unterstützung ist experimentell, und der Bot-Schutz von Kick kann manche Anfragen blockieren (Kick blockiert die Anfrage). Rechtsklick auf den Tab › Neu verbinden, oder schließe den Chat und öffne ihn erneut. Bleibt der Fehler bestehen, eröffne ein Issue mit chat.log.

„Kanal nicht gefunden“ Chat

Prüfe die Schreibweise und die gewählte Plattform: Ein allein eingegebener Name geht an die gewählte Schaltfläche. Füge lieber den Link des Kanals ein, der die Plattform von selbst wählt.

Der Steam-TV-Chat bleibt leer Chat

Den Chat gibt es nur während einer Übertragung. Solange offline, prüft Streamlink Chat alle 30 Sekunden erneut und zeigt die Nachrichten, sobald die Übertragung beginnt.

Ich kann nicht im Chat schreiben Chat

Du musst dein Konto verbinden (siehe Im Chat schreiben). Steam TV bleibt nur lesbar. Prüfe auf Twitch auch, dass du nicht aus dem Chat gesperrt bist und der Chat nicht nur für Abonnenten ist.

Die Kick-Anmeldung wird nicht abgeschlossen Chat
  • Prüfe, ob die Weiterleitungs-URL deiner Kick-Anwendung genau http://localhost:48125/callback lautet.
  • Prüfe Client ID und Client Secret (keine überzähligen Leerzeichen).
  • Port 48125 muss frei sein, und deine Firewall darf lokale Verbindungen nicht blockieren.
Nach einem PC-Wechsel muss ich mich neu anmelden Chat

Das ist normal: Unter Windows werden die Tokens für dein Konto auf diesem PC verschlüsselt. Woandershin kopiert, können sie nicht gelesen werden. Melde dich unter Einstellungen › Konten erneut an.

Manche Emotes erscheinen als Text Chat

Tk zeigt nur PNG und GIF an. Ein Emote, das nur als WebP oder AVIF angeboten wird, bleibt Text. Prüfe auch, ob sein Anbieter (BetterTTV, FrankerFaceZ, 7TV) unter Einstellungen › Emotes eingeschaltet ist und ob es für diese Plattform verfügbar ist (siehe Emotes und Plattformen).

Der Chat braucht viel Arbeitsspeicher Chat

Animierte Emotes kosten am meisten. Seit 0.2.1 bewegen sie sich nur im angezeigten Chat, und der Cache ist begrenzt. Du kannst den Speicherbedarf weiter senken, indem du Animierte Emotes ausschaltest oder 500 Nachrichten pro Chat behältst (Einstellungen › Anzeige).

Das integrierte Update schlägt fehl Launcher Chat

Die App muss ihre eigene Datei ersetzen können: Lege die .exe in einen eigenen Ordner (zum Beispiel Documents\Streamlink), nicht in C:\Program Files. Schlägt es fehl, wird die alte Version wiederhergestellt; die neue kannst du jederzeit von der Versionsseite herunterladen.

Eine Einstellungsdatei ist beschädigt Launcher Chat

Beim Start versucht die App ihre .bak-Kopie; der Launcher legt die beschädigte Datei außerdem als .corrupt beiseite und warnt dich. Um von vorn zu beginnen, schließe die App und benenne die betreffende Datei um: Sie wird mit den Standardeinstellungen neu angelegt.

Keine Ergebnisse. Versuche ein anderes Wort oder stelle deine Frage auf GitHub.

15 · Deinstallation

Sauber deinstallieren

Die Apps installieren nichts: Es genügt, ihre Dateien zu löschen. Ein paar Vorkehrungen vermeiden Reste.

Der Launcher unter Windows Launcher

  1. Ist Mit Windows starten aktiviert, schalte es zuerst unter Einstellungen › Fenster und Tastenkombination aus.
  2. Merke dir, wo deine Daten liegen: Einstellungen › Über › Datenordner öffnen. Wenn du deine Favoriten behalten willst, mache ein Exportieren….
  3. Beende den Launcher: Rechtsklick auf sein Symbol neben der Uhr › Beenden.
  4. Lösche die .exe, dann den Datenordner (config.json, platforms.json, streams/, launcher.log und die .bak-Dateien), neben der .exe oder in %APPDATA%\Streamlink Launcher.

Schon gelöscht, ohne den Autostart auszuschalten? Deaktiviere den Eintrag im Task-Manager › Autostart-Apps oder lösche den Wert StreamlinkLauncher aus HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

Der Chat unter Windows Chat

  1. Klicke unter Einstellungen › Konten für jedes Konto auf Abmelden und widerrufe, wenn du willst, den Zugriff bei Twitch oder Kick (siehe Im Chat schreiben).
  2. Schließe den Chat.
  3. Lösche die .exe, chat.json und seine .bak, den Ordner cache/ und chat.log, neben der .exe oder in %APPDATA%\Streamlink Chat.

Unter Linux Launcher Chat

Lösche das AppImage, dann die Datenordner:

$ rm -r ~/.config/streamlink-launcher ~/.config/streamlink-chat

Hast du mit Gear Lever oder AppImageLauncher einen Menüeintrag angelegt, entferne ihn in diesem Werkzeug.

Und Streamlink?

Es wird separat deinstalliert, so wie du es installiert hast: Windows-Einstellungen › Apps für das Installationsprogramm, winget uninstall streamlink, pip uninstall streamlink oder der Paketmanager deiner Distribution. Seine Konfigurationsdatei liegt in %APPDATA%\streamlink oder ~/.config/streamlink.

16 · Community

Fehler melden und mitmachen

Bevor du ein Issue eröffnest

  • Aktualisiere die App: Nur die neueste Version erhält Korrekturen.
  • Durchsuche die bestehenden Issues (Launcher, Chat): Das Problem ist vielleicht schon bekannt.
  • Lies die Fehlerbehebung durch.

Was hineingehört

  • Die App und ihre Version (Einstellungen › Über oder Einstellungen › Updates).
  • Dein System (Windows 11, Ubuntu 24.04…) und die Art der Installation: .exe, AppImage oder Quellcode.
  • Die Streamlink-Version: streamlink --version.
  • Was du getan hast, was du erwartet hast und was passiert ist. Bei einem Chat die Plattform und den Kanal.
  • Das Protokoll: launcher.log oder chat.log (und .log.1, falls vorhanden) im Datenordner. Bei einem Stream, der nicht startet, kopiere auch den Text aus dem Protokollbereich.

Lies das Protokoll, bevor du es sendest. Es kann Kanalnamen oder Pfade deines PCs enthalten; entferne alles, was du nicht öffentlich machen willst.

Eröffne dann ein Issue: Launcher oder Chat.

Eine Sicherheitslücke?

Eröffne kein öffentliches Issue. Nutze das private Formular von GitHub (Launcher, Chat) mit der Version, den Schritten zur Reproduktion und den Auswirkungen. Du erhältst innerhalb von etwa einer Woche eine Antwort.

Mitmachen

Fehlerberichte, Übersetzungen und Pull Requests sind willkommen.

  1. Für alles, was über eine kleine Korrektur hinausgeht, eröffne zuerst ein Issue, um es zu besprechen.
  2. Du brauchst nur Python 3.10 oder neuer, ohne Abhängigkeiten von Drittanbietern. Für die Oberfläche wird Tkinter benötigt.
  3. Führe vor dem Pull Request die Prüfungen aus:
$ python -m unittest discover -s tests -v $ python -m pip install ruff && python -m ruff check . $ xvfb-run -a python -m unittest tests.test_gui
  • Füge in CHANGELOG.md unter Unreleased eine Zeile hinzu, auf Englisch und auf Französisch.
  • Versionen veröffentlicht der Maintainer.

Die Apps übersetzen

Die Texte liegen in lang/*.json, eine Datei pro Sprache (fr, en, es, de, it). Jede Sprache muss genau dieselben Schlüssel haben: Ein Test prüft das. Für eine neue Sprache kopierst du en.json, übersetzt die Werte, ohne die Schlüssel oder die {Variablen} anzufassen, und hältst die Texte kurz, vor allem im Launcher.
