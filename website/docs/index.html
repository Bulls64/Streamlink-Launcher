01 · Présentation

Qu'est-ce que Streamlink Launcher et Streamlink Chat ?

Launcher

Une interface légère pour Streamlink. Tape le nom d'une chaîne ou colle un lien, appuie sur Entrée, et le stream s'ouvre dans ton lecteur vidéo (VLC, mpv, PotPlayer…) au lieu du navigateur. Il retient tes favoris, te dit lesquels sont en direct et ouvre une barre mini avec Ctrl+Alt+S.

Chat

Le compagnon du lanceur, dans l'esprit de Chatterino : les chats Twitch, Kick et Steam TV dans une seule fenêtre, un onglet par chat, chacun à la couleur de sa plateforme. Lecture sans compte, écriture sur Twitch et Kick après connexion, et ▶ pour ouvrir le stream avec Streamlink.

Plateformes prises en charge

PlateformeLauncherChat
TwitchOui, sans publicitésLecture et écriture
KickOuiLecture et écriture (expérimental)
Steam TVOuiLecture seule
YouTube, DailymotionOuiNon
Lien directTout site pris en charge par StreamlinkNon

Configuration requise

  • Windows 10 ou 11 : un .exe d'un seul fichier, sans installation.
  • Linux x86_64 : une AppImage qui embarque son propre Python. Il faut la glibc 2.35 ou plus récente (Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 ou plus récents).
  • Depuis les sources : Python 3.10 ou plus récent avec Tcl/Tk, aucune autre dépendance.
  • Pour regarder : Streamlink et un lecteur vidéo, VLC par défaut.

Sous Linux, le lanceur n'a pas l'icône de notification, le raccourci global, le démarrage automatique, le glisser-déposer, les notifications de live, les aperçus des streams ni la mise à jour intégrée.

Langues

Les deux applis existent en français, anglais, espagnol, allemand et italien. Elles suivent la langue du système ; tu peux la changer dans Paramètres › Général (Launcher) ou Paramètres › Affichage (Chat).

03 · Le moteur

Qu'est-ce que Streamlink ?

Streamlink est un programme libre en ligne de commande. Il récupère le flux vidéo d'un stream et l'envoie à ton lecteur. Tu regardes donc Twitch, Kick ou YouTube dans VLC ou mpv, sans la page web autour : moins de mémoire, pas de publicité Twitch, et les raccourcis de ton lecteur.

Streamlink s'utilise normalement dans un terminal :

$ streamlink https://www.twitch.tv/eslcs best

Streamlink Launcher écrit cette commande pour toi : il reconnaît la plateforme, ajoute les bonnes options et la qualité choisie, puis lance Streamlink. Streamlink Chat s'en sert pour son bouton ▶.

Les qualités

best prend la meilleure qualité, worst la plus basse, audio_only le son seul (Twitch). Tu peux aussi demander une qualité précise comme 1080p60, ou une liste de secours : 720p60,720p,best prend la première disponible.

Et les publicités Twitch ?

Depuis la version 7.5.0, Streamlink retire toujours les publicités des streams Twitch. L'ancienne option --twitch-disable-ads est devenue inutile (elle est dépréciée, mais encore acceptée).

Streamlink est un projet indépendant. Les deux applis ne l'incluent pas : il faut l'installer à part, une seule fois.

04 · Installation

Où télécharger Streamlink et comment l'installer ?

Streamlink se télécharge depuis son site officiel, streamlink.github.io/install. Choisis ton système :

Windows : l'installateur (recommandé)

  1. Ouvre la page des releases Windows de Streamlink.
  2. Télécharge l'installateur .exe de la dernière version (Windows 10 ou plus récent, x86_64).
  3. Lance-le et suis les étapes. Il ajoute Streamlink au PATH : le lanceur le trouve tout seul.

Ou avec un gestionnaire de paquets

# winget (inclus dans Windows 11) > winget install streamlink # Chocolatey > choco install streamlink # Scoop > scoop bucket add extras > scoop install streamlink

Linux : le paquet de ta distribution

# Fedora $ sudo dnf install streamlink # Arch Linux $ sudo pacman -S streamlink # Debian testing / sid $ sudo apt update && sudo apt install streamlink

Ubuntu et dérivées : le site de Streamlink déconseille le paquet Ubuntu, qui n'est pas maintenu. Utilise plutôt l'installation Python (onglet suivant) ou l'AppImage de Streamlink, proposée sur la même page.

Il te faut aussi un lecteur, par exemple sudo apt install mpv ou sudo dnf install vlc.

Avec Python (tous systèmes)

Demande Python 3.10 ou plus récent.

$ pip install -U streamlink

La même commande met Streamlink à jour. Sous Linux, préfère un environnement virtuel ou pipx install streamlink pour ne pas toucher au Python du système.

Vérifier l'installation

$ streamlink --version

Si la commande affiche un numéro de version, c'est bon. Dans Launcher, Paramètres › Streamlink affiche aussi la version trouvée.

Streamlink installé ailleurs ? Launcher Chat

Les applis cherchent Streamlink dans le PATH et aux emplacements habituels. S'il est ailleurs, indique le chemin de streamlink.exe dans Paramètres › Streamlink › Chemin personnalisé (Launcher) ou Paramètres › Regarder (Chat).

05 · Démarrer

Premiers pas

Où ranger les applis Launcher Chat

Télécharge le fichier depuis la page des releases (Launcher, Chat) et place-le dans un dossier à toi, par exemple Documents\Streamlink. Les réglages se rangent à côté, et la mise à jour intégrée peut remplacer le fichier. Évite C:\Program Files, qui est protégé en écriture.

Sous Linux, rends l'AppImage exécutable puis lance-la :

$ chmod +x StreamlinkLauncher-*-x86_64.AppImage $ ./StreamlinkLauncher-*-x86_64.AppImage

Pour une entrée dans le menu des applications, utilise un outil comme Gear Lever ou AppImageLauncher.

Ton premier stream Launcher

  1. Vérifie que Streamlink et un lecteur vidéo sont installés.
  2. Choisis la plateforme avec sa pastille : Twitch, Kick, YouTube, Dailymotion, Steam TV ou Lien direct.
  3. Tape le nom de la chaîne (eslcs) ou colle un lien (https://kick.com/…) : un lien choisit la plateforme tout seul.
  4. Choisis la qualité si besoin, puis Entrée ou Lancer. Le lecteur s'ouvre après quelques secondes.
  5. Pour suivre ou arrêter le stream, ouvre le Journal en bas de la fenêtre : il montre la sortie de Streamlink et un bouton Arrêter.

Trois façons plus rapides Launcher

  • Copier un lien : copie l'adresse d'un stream, puis reviens sur le lanceur. Il propose de le lancer, et le lien est déjà dans la barre mini. Désactivable dans Paramètres › Streamlink › Détecter les liens copiés.
  • Glisser-déposer (Windows) : fais glisser l'adresse depuis la barre du navigateur, un texte sélectionné ou un raccourci Internet .url sur la fenêtre.
  • Mode mini (Windows) : Ctrl+Alt+S depuis n'importe quelle application, tape, Entrée.

Ton premier chat Chat

  1. Choisis la plateforme avec sa pastille, sous le champ Ajouter un chat.
  2. Tape le nom de la chaîne ou colle un lien, puis Entrée. Ctrl+T place le curseur dans ce champ.
  3. Le chat s'ouvre dans un nouvel onglet, en lecture seule. Pour écrire, connecte ton compte (voir Écrire dans le chat).
  4. Dans l'en-tête du chat, ▶ ouvre le stream avec Streamlink et l'icône de lien ouvre la chaîne dans ton navigateur.

Le champ accepte un nom (eslcs), un préfixe (kick:lunaria, steam:nom) ou un lien : twitch.tv/…, kick.com/…, steam.tv/…, steamcommunity.com/broadcast/watch/…, liens « popout » compris. Tes onglets reviennent au démarrage suivant.

07 · Au quotidien

Comment gérer l'historique et les favoris ?

Ajouter un favori Launcher

  1. Choisis la plateforme avec sa pastille (Twitch, Kick…) et tape le nom de la chaîne.
  2. Clique sur la carte Ajouter un favori sur l'écran principal.

L'écran principal affiche les favoris de la plateforme choisie, ceux en direct d'abord. Tout voir ouvre la liste complète.

Lancer, modifier ou retirer un favori Launcher

  • Lancer : clique sur sa carte.
  • Plus d'options : clic droit sur la carte, puis Lancer, Remplir le champ ou Retirer des favoris.
  • Dans le panneau Favoris : un clic sur une ligne remplit le champ, ▶ lance, la corbeille retire.

Qui est en direct ? Launcher

Avec Paramètres › En direct › Vérifier qui est en direct, le lanceur vérifie tes favoris Twitch et Kick tant qu'il est ouvert, toutes les 2, 5, 10, 15 ou 30 minutes (5 par défaut). Aperçu des lives ajoute l'image, le titre et le nombre de spectateurs des favoris Twitch en direct, et Notification Windows te prévient quand un favori commence un live : clique sur la notification pour regarder.

L'historique Launcher

  • Les 200 derniers lancements sont gardés. Les plus récents s'affichent sous Récents ; ▶ relance directement.
  • Historique complet ouvre le panneau : un clic remplit le champ, ▶ relance, la corbeille efface une entrée, Tout effacer vide l'historique.
  • Les suggestions du champ de saisie viennent de tes favoris puis de ton historique : utilise ↓ ↑ puis Entrée.

Sauvegarder ou copier sur un autre PC Launcher

Paramètres › Sauvegarde › Exporter… enregistre tes réglages et tes favoris dans un seul fichier. Importer… les restaure et te laisse choisir : Oui ajoute les favoris importés aux tiens, Non remplace tes favoris, Annuler ne change rien. Les chemins propres à l'ordinateur (Streamlink, lecteur, scripts) ne sont pas inclus, et l'historique non plus.

Et dans le chat ? Chat

Streamlink Chat n'a pas de favoris : les chats ouverts reviennent tout seuls au démarrage suivant. Ferme un chat avec Ctrl+W ou un clic du milieu sur son onglet. Pour ouvrir toujours les mêmes chats d'un coup, vois la recette Ouvrir ses chats depuis un raccourci.

08 · Comptes

Écrire dans le chat

La lecture ne demande aucun compte. Pour écrire, il faut ta propre application, gratuite, sur chaque plateforme : ainsi, aucun secret n'est livré avec le programme. C'est à faire une seule fois.

Connecter Twitch Chat

  1. Ouvre dev.twitch.tv/console/apps/create et connecte-toi avec ton compte Twitch. Twitch peut te demander d'activer la double authentification pour accéder à la console.
  2. Donne un nom à l'application, ajoute l'URL de redirection http://localhost, choisis la catégorie Chat Bot et le type de client Public, puis crée-la.
  3. Copie son Client ID et colle-le dans Paramètres › Comptes (pour écrire).
  4. Clique sur Se connecter à Twitch. Une page twitch.tv/activate s'ouvre : saisis le code affiché par l'appli et autorise-la.
  5. L'en-tête des chats Twitch passe à Connecté. La connexion se renouvelle toute seule.

L'appli ne demande que deux autorisations : lire et écrire dans le chat (chat:read, chat:edit).

Connecter Kick Chat

  1. Ouvre les paramètres développeur de Kick et crée une application.
  2. Déclare l'URL de redirection http://localhost:48125/callback et coche les autorisations lire les infos et écrire dans le chat.
  3. Colle son Client ID et son Client Secret dans Paramètres › Comptes (pour écrire).
  4. Clique sur Se connecter à Kick : ton navigateur s'ouvre sur Kick, autorise l'application. Kick te renvoie vers localhost:48125, où l'appli attend la réponse.

Le port 48125 doit être libre pendant la connexion. Si un autre programme l'utilise, ferme-le le temps de te connecter.

Steam TV Chat

Steam ne permet pas d'écrire dans le chat d'une diffusion depuis un autre programme : Steam TV reste en lecture seule, sans compte.

Où sont gardés les jetons ? Chat

  • Dans chat.json. Sous Windows, ils sont chiffrés avec DPAPI : seul ton compte Windows, sur ce PC, peut les relire.
  • Sous Linux, ils sont enregistrés en clair dans ton dossier personnel. Ne partage pas ce fichier.
  • Si tu copies chat.json sur un autre PC, les jetons y sont illisibles : reconnecte-toi.

Se déconnecter et retirer l'accès Chat

  • Se déconnecter, dans Paramètres › Comptes, efface les jetons de ton PC.
  • Pour retirer aussi l'accès côté Twitch, ouvre Paramètres › Connexions sur Twitch et déconnecte ton application.
  • Côté Kick, supprime l'application dans les paramètres développeur.

Formats, animations et cache Chat

10 · Recettes

Recettes pour aller plus vite

Choisir le lecteur du bouton ▶ Chat

Le chat lance Streamlink sans option de lecteur : Streamlink utilise donc celui de son fichier de configuration, VLC par défaut. Pour passer à mpv, crée ce fichier (sans extension) et ajoute :

configplayer=mpv player-args=--force-window=immediate
SystèmeFichier de configuration de Streamlink
Windows%APPDATA%\streamlink\config
Linux~/.config/streamlink/config

Si mpv n'est pas dans le PATH, mets son chemin complet après player=. Launcher utilise aussi ce fichier quand Paramètres › Lecteur vidéo est sur Par défaut (réglage de Streamlink).

Regarder avec moins de retard

Streamlink a un mode faible latence pour Twitch et Kick. Le plus simple est de l'activer pour une seule plateforme, avec un fichier de configuration propre à son plugin, à côté du fichier config :

config.twitchtwitch-low-latency
config.kickkick-low-latency

Ça marche pour les deux applis. Le gain dépend du diffuseur, qui doit avoir activé la faible latence ; la lecture peut un peu plus souvent se mettre en mémoire tampon.

Enregistrer un stream en le regardant

Dans un terminal, --record écrit le flux dans un fichier pendant que tu regardes :

$ streamlink --record "{author}-{time:%Y%m%d-%H%M}.ts" https://www.twitch.tv/eslcs best

{author} devient le nom de la chaîne et {time:…} la date et l'heure. Ouvre le .ts avec VLC ou mpv.

Launcher Pour le faire depuis le lanceur, ajoute une plateforme dédiée dans platforms.json (lien Modifier platforms.json en bas des paramètres), avec un chemin complet vers ton dossier de vidéos :

platforms.json (une entrée de plus dans la liste "platforms"){ "id": "twitch-rec", "name": "Twitch REC", "input": "channel", "url": "https://www.twitch.tv/{arg}", "hosts": [], "args": ["--record", "C:\\Users\\toi\\Videos\\{author}-{time:%Y%m%d-%H%M}.ts"], "qualities": ["best", "1080p60", "720p60", "480p"], "color": "#E91916", "text_color": "#FFFFFF", "live_check": "none" }

Redémarre le lanceur : une pastille Twitch REC apparaît. hosts reste vide pour que les liens Twitch collés continuent d'aller vers la pastille Twitch normale. Dans le JSON, chaque \ d'un chemin Windows s'écrit \\.

Ne jamais tomber sur « qualité introuvable »

Toutes les chaînes ne proposent pas toutes les qualités. Launcher Dans la liste des qualités, choisis Personnalisée… et saisis une liste de secours comme 720p60,720p,best : Streamlink prend la première qui existe, et le lanceur la retient pour cette plateforme. Chat La qualité du bouton ▶ se choisit dans une liste fixe ; garde best si tu regardes des chaînes très différentes.

Ouvrir ses chats depuis un raccourci Chat

Streamlink Chat accepte des chats en arguments. Crée un raccourci Windows (clic droit sur le bureau › Nouveau › Raccourci) avec une cible comme :

"C:\Users\toi\Documents\Streamlink\StreamlinkChat.exe" --open twitch:eslcs --open kick:lunaria

Si le chat est déjà ouvert, ces chats s'ajoutent à la fenêtre existante. Un lien de chaîne marche aussi comme argument.

Astuce : renomme d'abord l'exécutable sans numéro de version, par exemple StreamlinkChat.exe. Un fichier nommé d'après sa version change de nom à chaque mise à jour, et le raccourci ne le trouverait plus. Un nom sans version est gardé.

Démarrer le lanceur réduit Launcher

Paramètres › Fenêtre et raccourci › Lancer au démarrage de Windows le démarre dans la zone de notification. Tu peux faire pareil avec ton propre raccourci, en ajoutant --tray après le chemin de l'exécutable.

Garder ses anciens scripts .bat Launcher

Si tu lançais tes streams avec des scripts, active Paramètres › Avancé › Afficher les scripts .bat et choisis le Dossier des scripts. Une pastille Scripts liste les fichiers .bat, .cmd, .ps1, .exe, .py et .lnk de ce dossier. Le champ te permet de passer un argument au script (lettres, chiffres, ., _ et - uniquement).

11 · Mises à jour

Comment mettre à jour l'application ?

Le lanceur Launcher

  1. Ouvre Paramètres › À propos : la carte indique ta version et la dernière publiée sur GitHub.
  2. Si une version plus récente existe, clique sur Mettre à jour. Le lanceur télécharge le nouvel .exe, vérifie sa taille et son empreinte SHA-256, le met à la place de l'ancien et redémarre.
  • Vérifier les mises à jour au démarrage fait la vérification tout seul.
  • Mises à jour automatiques du lanceur installe aussi la nouvelle version au démarrage, jamais pendant un stream.
  • Un fichier nommé d'après sa version (StreamlinkLauncher-1.4.2.exe) prend le nouveau numéro ; le démarrage avec Windows suit le nouveau nom.

Le chat Chat

Même principe dans Paramètres › Mises à jour : Vérifier, puis Mettre à jour. Le chat redémarre avec tes chats ouverts. Une pastille sur le bouton des paramètres signale une nouvelle version, et Mises à jour automatiques (désactivé par défaut) fait tout seul au démarrage.

AppImage ou sources : la mise à jour en un clic ne concerne que l'.exe Windows placé dans un dossier modifiable (pas C:\Program Files). Avec l'AppImage, Mettre à jour ouvre la page de la release : télécharge la nouvelle AppImage et remplace l'ancienne. Depuis les sources, fais un git pull.

Mettre à jour Streamlink lui-même

Le lanceur compare ta version de Streamlink à la dernière publiée. Si elle est plus ancienne, la carte de Paramètres › Streamlink propose Mettre à jour : avec l'installateur Windows, elle ouvre la page de téléchargement ; avec pip, elle copie la commande pip install -U streamlink. Avec winget, Chocolatey, Scoop ou ta distribution Linux, utilise leur commande de mise à jour habituelle (winget upgrade streamlink, par exemple).

12 · Réglages

Autres questions sur les réglages

Comment choisir mon lecteur vidéo ? Launcher

Paramètres › Lecteur vidéo : choisis VLC, mpv, PotPlayer ou un autre programme, et indique son chemin s'il n'est pas trouvé. Arguments du lecteur ajoute des options, par exemple --fullscreen. Par défaut (réglage de Streamlink) laisse Streamlink choisir (voir la recette).

Comment changer la qualité par défaut ? Launcher Chat

Dans le lanceur, la liste à côté du champ retient la qualité par plateforme ; Personnalisée… accepte une qualité précise ou une liste de secours. Dans le chat, c'est Paramètres › Regarder › Qualité, utilisée par le bouton ▶.

Comment changer le raccourci du mode mini ? Launcher

Paramètres › Fenêtre et raccourci : active ou désactive Raccourci global et choisis une autre combinaison que Ctrl+Alt+S. L'état du raccourci y est affiché.

Le lanceur peut-il rester ouvert en arrière-plan ? Launcher

Oui : avec Réduire dans la zone de notification, fermer la fenêtre laisse le lanceur à côté de l'horloge, avec tes streams et la surveillance des lives. Clic droit sur l'icône pour rouvrir la fenêtre, ouvrir le mode mini, lancer un favori en direct ou Quitter. Lancer au démarrage de Windows le démarre réduit.

Comment désactiver la détection des liens copiés ? Launcher

Décoche Détecter les liens copiés dans Paramètres › Streamlink. Le presse-papiers n'est lu que sur ton ordinateur ; rien n'est enregistré ni envoyé.

Puis-je enlever les couleurs par plateforme ? Launcher Chat

Oui : Couleurs par plateforme dans Paramètres › Général (Launcher) ou Paramètres › Affichage (Chat).

Comment ajouter une plateforme ? Launcher

Le lien Modifier platforms.json, en bas du panneau des paramètres, ouvre le fichier. Chaque entrée donne :

  • id et name : un identifiant unique et le nom de la pastille ;
  • input : channel, youtube, video, url (n'importe quel lien) ou none (rien à saisir) ;
  • url : le modèle d'adresse, où {arg} est remplacé par ce que tu tapes ;
  • hosts : les domaines qui choisissent cette pastille quand tu colles un lien ;
  • args : des options Streamlink en plus ;
  • qualities, color, text_color ;
  • live_check : twitch, streamlink ou none.

Enregistre, puis redémarre le lanceur pour voir la nouvelle pastille. Exemple complet dans la recette Enregistrer un stream.

Comment écrire dans un chat ? Chat

Connecte ton compte Twitch ou Kick dans Paramètres › Comptes (pour écrire). Les étapes sont détaillées dans Écrire dans le chat.

Quels réglages d'affichage propose le chat ? Chat

Paramètres › Affichage : langue, thème, taille du texte, heure des messages, badges, emotes animées, couleurs par plateforme et nombre de messages gardés par chat (500, 1000, 2000 ou 5000). Emotes active ou désactive BetterTTV, FrankerFaceZ et 7TV. Mentions surligne les messages qui citent ton pseudo ou des mots de ton choix, séparés par des virgules.

14 · Dépannage

Dépannage (FAQ)

« Streamlink introuvable » Launcher Chat

Installe Streamlink (voir Installer Streamlink), puis redémarre l'appli. S'il est installé ailleurs, indique le chemin de streamlink.exe dans les Paramètres. Vérifie dans un terminal que streamlink --version répond.

Le stream ne démarre pas Launcher

Ouvre le tiroir du journal en bas de la fenêtre : le message d'erreur de Streamlink s'y affiche. Les causes les plus fréquentes :

  • No playable streams found : la chaîne est hors ligne, ou le nom est mal écrit.
  • La qualité demandée n'existe pas pour ce stream : choisis best ou une liste de secours avec Personnalisée….
  • Le lecteur vidéo n'est pas trouvé : indique son chemin dans Paramètres › Lecteur vidéo.
Le stream saccade ou se coupe Launcher Chat

Essaie une qualité plus basse (720p, 480p) : elle demande moins de débit. Si tu as activé la faible latence, retire-la. Les messages du journal t'indiquent si Streamlink attend des données.

Le son est là, mais pas l'image Launcher

Vérifie que la qualité choisie n'est pas audio_only. Sinon, mets ton lecteur à jour ; avec mpv, l'option --force-window=immediate ouvre la fenêtre tout de suite.

Windows affiche « Windows a protégé votre ordinateur » Launcher Chat

Les exécutables ne sont pas encore signés, donc SmartScreen avertit au premier lancement. Ce n'est pas une détection.

  1. Vérifie le fichier : dans PowerShell, Get-FileHash .\StreamlinkLauncher-1.5.1.exe, et compare avec SHA256SUMS.txt de la release.
  2. Clique sur Informations complémentaires, puis Exécuter quand même.
  3. Si rien ne se passe au double-clic : clic droit › Propriétés › coche Débloquer, ou Unblock-File .\StreamlinkLauncher-1.5.1.exe.
Mon antivirus bloque ou supprime l'exe Launcher Chat

Les programmes compilés avec PyInstaller sont parfois détectés à tort. Vérifie le SHA-256, restaure le fichier depuis la quarantaine, ajoute son dossier aux exclusions, et signale le faux positif (Microsoft Defender : envoyer un fichier, catégorie Incorrectly detected as malware). Tu peux aussi lancer l'appli depuis les sources.

Ctrl+Alt+S ne fait rien Launcher

Une autre application utilise sans doute ce raccourci. Le lanceur t'en avertit au démarrage ; choisis-en un autre dans Paramètres › Fenêtre et raccourci. Chaque appui reçu est noté dans le journal. Le raccourci global n'existe que sous Windows.

Le lanceur ne s'ouvre pas une deuxième fois Launcher Chat

C'est voulu : une seule copie de chaque appli tourne à la fois. Le lanceur est sans doute dans la zone de notification, à côté de l'horloge. Pour le chat, une nouvelle ouverture envoie ses chats à la fenêtre déjà ouverte.

« Dossier du lanceur protégé en écriture » Launcher

Le lanceur ne peut pas écrire à côté de son .exe (par exemple dans C:\Program Files). Il range alors ses données dans %APPDATA%\Streamlink Launcher. Tout marche, mais la mise à jour intégrée ne pourra pas remplacer le fichier : déplace-le dans un dossier à toi.

L'AppImage ne se lance pas Launcher Chat
  • Rends-la exécutable : chmod +x suivi du nom du fichier.
  • Message sur FUSE : installe libfuse2, ou lance-la avec --appimage-extract-and-run.
  • Erreur sur GLIBC : ton système est trop ancien (glibc 2.35 minimum). Lance l'appli depuis les sources.
Un chat Kick reste en erreur Chat

Kick a changé son système de chat le 13 octobre 2026 et ne le documente pas : la prise en charge est expérimentale, et la protection anti-robots de Kick peut bloquer certaines requêtes (Kick bloque la requête). Clic droit sur l'onglet › Reconnecter, ou ferme puis rouvre le chat. Si l'erreur persiste, ouvre un ticket avec chat.log.

« Chaîne introuvable » Chat

Vérifie l'orthographe et la plateforme choisie : un nom tapé seul va vers la pastille sélectionnée. Colle plutôt le lien de la chaîne, qui choisit la plateforme tout seul.

Le chat Steam TV reste vide Chat

Le chat n'existe que pendant une diffusion. Hors ligne, Streamlink Chat revérifie toutes les 30 secondes et affiche les messages dès que la diffusion commence.

Je ne peux pas écrire dans le chat Chat

Il faut connecter ton compte (voir Écrire dans le chat). Steam TV reste en lecture seule. Sur Twitch, vérifie aussi que tu n'es pas exclu du chat et que le salon n'est pas réservé aux abonnés ou aux abonnés de la chaîne.

La connexion Kick n'aboutit pas Chat
  • Vérifie que l'URL de redirection de ton application Kick est exactement http://localhost:48125/callback.
  • Vérifie le Client ID et le Client Secret (sans espace en trop).
  • Le port 48125 doit être libre, et ton pare-feu ne doit pas bloquer les connexions locales.
Je dois me reconnecter après avoir changé de PC Chat

Normal : sous Windows, les jetons sont chiffrés pour ton compte sur ce PC. Copiés ailleurs, ils sont illisibles. Reconnecte-toi dans Paramètres › Comptes.

Certaines emotes s'affichent en texte Chat

Tk n'affiche que les PNG et les GIF. Une emote proposée seulement en WebP ou AVIF reste écrite en texte. Vérifie aussi que son fournisseur (BetterTTV, FrankerFaceZ, 7TV) est activé dans Paramètres › Emotes, et qu'il est disponible pour cette plateforme (voir Emotes et plateformes).

Le chat utilise beaucoup de mémoire Chat

Les emotes animées sont les plus coûteuses. Depuis la 0.2.1, elles ne s'animent que dans le chat affiché et le cache est plafonné. Tu peux encore réduire la mémoire en désactivant Emotes animées ou en gardant 500 messages par chat (Paramètres › Affichage).

La mise à jour intégrée échoue Launcher Chat

L'appli doit pouvoir remplacer son propre fichier : place l'.exe dans un dossier à toi (par exemple Documents\Streamlink), pas dans C:\Program Files. En cas d'échec, l'ancienne version est remise en place ; tu peux toujours télécharger la nouvelle depuis la page des releases.

Un fichier de réglages est endommagé Launcher Chat

Au démarrage, l'appli essaie sa copie .bak et, pour le lanceur, met le fichier abîmé de côté en .corrupt et te prévient. Pour repartir de zéro, ferme l'appli et renomme le fichier en question : il sera recréé avec les réglages par défaut.

Aucun résultat. Essaie un autre mot, ou pose ta question sur GitHub.

15 · Désinstaller

Désinstaller proprement

Les applis ne s'installent pas : il suffit de supprimer leurs fichiers. Quelques précautions évitent les restes.

Le lanceur sous Windows Launcher

  1. Si Lancer au démarrage de Windows est activé, désactive-le d'abord dans Paramètres › Fenêtre et raccourci.
  2. Note où sont tes données : Paramètres › À propos › Ouvrir le dossier des données. Si tu veux garder tes favoris, fais un Exporter….
  3. Quitte le lanceur : clic droit sur son icône près de l'horloge › Quitter.
  4. Supprime l'.exe, puis le dossier des données (config.json, platforms.json, streams/, launcher.log et les .bak), à côté de l'.exe ou dans %APPDATA%\Streamlink Launcher.

Déjà supprimé sans désactiver le démarrage ? Désactive l'entrée dans le Gestionnaire des tâches › Applications de démarrage, ou supprime la valeur StreamlinkLauncher de HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

Le chat sous Windows Chat

  1. Dans Paramètres › Comptes, clique sur Se déconnecter pour chaque compte, puis retire l'accès côté Twitch ou Kick si tu veux (voir Écrire dans le chat).
  2. Ferme le chat.
  3. Supprime l'.exe, chat.json et sa .bak, le dossier cache/ et chat.log, à côté de l'.exe ou dans %APPDATA%\Streamlink Chat.

Sous Linux Launcher Chat

Supprime l'AppImage, puis les dossiers de données :

$ rm -r ~/.config/streamlink-launcher ~/.config/streamlink-chat

Si tu as créé une entrée de menu avec Gear Lever ou AppImageLauncher, retire-la depuis cet outil.

Et Streamlink ?

Il se désinstalle à part, comme tu l'as installé : Paramètres Windows › Applications pour l'installateur, winget uninstall streamlink, pip uninstall streamlink ou le gestionnaire de paquets de ta distribution. Son fichier de configuration est dans %APPDATA%\streamlink ou ~/.config/streamlink.

16 · Communauté

Signaler un bug et contribuer

Avant d'ouvrir un ticket

  • Mets l'appli à jour : seule la dernière version reçoit des correctifs.
  • Cherche dans les tickets existants (Launcher, Chat) : le problème est peut-être déjà connu.
  • Parcours le dépannage.

Ce qu'il faut indiquer

  • L'appli et sa version (Paramètres › À propos ou Paramètres › Mises à jour).
  • Ton système (Windows 11, Ubuntu 24.04…) et le type d'installation : .exe, AppImage ou sources.
  • La version de Streamlink : streamlink --version.
  • Ce que tu as fait, ce que tu attendais et ce qui s'est passé. Pour un chat, la plateforme et la chaîne.
  • Le journal : launcher.log ou chat.log (et .log.1 s'il existe), dans le dossier des données. Pour un stream qui ne démarre pas, copie aussi le texte du tiroir du journal.

Relis le journal avant de l'envoyer. Il peut contenir des noms de chaînes ou des chemins de ton PC ; retire ce que tu ne veux pas rendre public.

Puis ouvre un ticket : Launcher ou Chat.

Une faille de sécurité ?

N'ouvre pas de ticket public. Utilise le formulaire privé de GitHub (Launcher, Chat) avec la version, les étapes pour reproduire et l'impact. Réponse sous environ une semaine.

Contribuer

Signalements, traductions et pull requests sont les bienvenus.

  1. Pour tout ce qui dépasse un petit correctif, ouvre d'abord un ticket pour en discuter.
  2. Il suffit de Python 3.10 ou plus récent, sans aucune dépendance tierce. Tkinter sert pour l'interface.
  3. Lance les vérifications avant la pull request :
$ python -m unittest discover -s tests -v $ python -m pip install ruff && python -m ruff check . $ xvfb-run -a python -m unittest tests.test_gui
  • Ajoute une ligne sous Unreleased dans CHANGELOG.md, en anglais et en français.
  • Les versions sont publiées par le mainteneur.

Traduire les applis

Les textes sont dans lang/*.json, un fichier par langue (fr, en, es, de, it). Toutes les langues doivent avoir exactement les mêmes clés : un test le vérifie. Pour une nouvelle langue, copie en.json, traduis les valeurs sans toucher aux clés ni aux {variables}, et garde des textes courts, surtout dans le lanceur.

Fonction de chiffrement de Windows : seul ton compte, sur ton PC, peut relire ce qu'elle protège. Elle protège les jetons du chat.

Petite image utilisée comme un mot dans le chat, par exemple KEKW.

Fichier sain signalé à tort par un antivirus.

Autre extension d'emotes pour Twitch.

Bibliothèque de base des systèmes Linux. Les AppImage demandent la version 2.35 ou plus récente.

Format de diffusion découpé en petits segments, utilisé par Twitch et Kick.

Ancien protocole de discussion sur lequel repose le chat de Twitch.
Jeton (token)
Clé temporaire que Twitch ou Kick donne à l'appli après ta connexion. Elle remplace ton mot de passe, que l'appli ne voit jamais.

Le tiroir en bas du lanceur, et les fichiers launcher.log et chat.log qui notent les erreurs.

Chat que tu peux lire mais pas écrire : sans compte connecté, ou toujours sur Steam TV.

Message qui cite ton pseudo ou un mot que tu as choisi. Il est surligné.

Méthode standard pour autoriser une appli à agir en ton nom sans lui donner ton mot de passe.

Liste des dossiers où le système cherche les programmes. Streamlink y est ajouté par son installateur.
platforms.json
Fichier du lanceur qui décrit les plateformes : adresse, options, qualités, couleur, statut en direct.

Partie de Streamlink qui sait lire un site précis (twitch, kick, steam…).
Portable
Une appli qui garde ses réglages à côté de son fichier : on peut la déplacer ou la copier sur une clé USB.
Pusher
Ancien système temps réel du chat de Kick, gardé en secours.
PyInstaller
Outil qui transforme un programme Python en un seul .exe.
Qualité
Définition du flux demandée à Streamlink : best, 1080p60, audio_only…
Release
Version publiée sur GitHub, avec ses fichiers à télécharger et SHA256SUMS.txt.
SHA-256
Empreinte d'un fichier. Si elle correspond à celle de la release, le fichier n'a pas été modifié.
SmartScreen
Protection de Windows qui avertit au premier lancement d'un programme récent ou non signé.
Streamlink
Programme libre qui récupère un stream et l'envoie à ton lecteur. Les deux applis s'en servent.

Zone en bas du lanceur : streams en cours, bouton Arrêter et sortie de Streamlink.
WebSocket
Connexion qui reste ouverte entre l'appli et le serveur pour recevoir les messages au fil de l'eau.
