01 · Overview

What are Streamlink Launcher and Streamlink Chat?

Launcher

A lightweight interface for Streamlink. Type a channel name or paste a link, press Enter, and the stream opens in your video player (VLC, mpv, PotPlayer…) instead of the browser. It remembers your favorites, tells you which ones are live and opens a mini bar with Ctrl+Alt+S.

Chat

The launcher's companion, in the spirit of Chatterino: Twitch, Kick and Steam TV chats in one window, one tab per chat, each in its platform's color. Read without an account, write on Twitch and Kick once logged in, and press ▶ to open the stream with Streamlink.

Supported platforms

PlatformLauncherChat
TwitchYes, without adsRead and write
KickYesRead and write (experimental)
Steam TVYesRead-only
YouTube, DailymotionYesNo
Direct linkAny site Streamlink supportsNo

Requirements

  • Windows 10 or 11: a single-file .exe, nothing to install.
  • Linux x86_64: an AppImage that bundles its own Python. It needs glibc 2.35 or newer (Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 or newer).
  • From source: Python 3.10 or newer with Tcl/Tk, no other dependency.
  • To watch: Streamlink and a video player, VLC by default.

On Linux, the launcher has no notification-area icon, global shortcut, start with the system, drag and drop, live notifications, stream previews or built-in update.

Languages

Both apps come in English, French, Spanish, German and Italian. They follow the system language; you can change it in Settings › General (Launcher) or Settings › Display (Chat).

03 · The engine

What is Streamlink?

Streamlink is a free command-line program. It fetches a stream's video feed and sends it to your player. So you watch Twitch, Kick or YouTube in VLC or mpv, without the web page around it: less memory, no Twitch ads, and your player's own shortcuts.

Streamlink is normally used in a terminal:

$ streamlink https://www.twitch.tv/eslcs best

Streamlink Launcher writes this command for you: it recognizes the platform, adds the right options and the chosen quality, then starts Streamlink. Streamlink Chat uses it for its ▶ button.

Qualities

best picks the highest quality, worst the lowest, audio_only sound only (Twitch). You can also ask for a specific quality such as 1080p60, or a fallback list: 720p60,720p,best takes the first one available.

What about Twitch ads?

Since version 7.5.0, Streamlink always filters out ads on Twitch streams. The old --twitch-disable-ads option is no longer needed (it is deprecated, but still accepted).

Streamlink is an independent project. Neither app includes it: you install it separately, once.

04 · Installation

Where to download Streamlink and how to install it?

Streamlink is available from its official website, streamlink.github.io/install. Choose your system:

Windows: the installer (recommended)

  1. Open the Streamlink Windows releases page.
  2. Download the .exe installer of the latest version (Windows 10 or newer, x86_64).
  3. Run it and follow the steps. It adds Streamlink to the PATH: the launcher finds it on its own.

Or with a package manager

# winget (included in Windows 11) > winget install streamlink # Chocolatey > choco install streamlink # Scoop > scoop bucket add extras > scoop install streamlink

Linux: your distribution's package

# Fedora $ sudo dnf install streamlink # Arch Linux $ sudo pacman -S streamlink # Debian testing / sid $ sudo apt update && sudo apt install streamlink

Ubuntu and derivatives: the Streamlink website advises against the Ubuntu package, which is not maintained. Use the Python install (next tab) or the Streamlink AppImage, offered on the same page.

You also need a player, for example sudo apt install mpv or sudo dnf install vlc.

With Python (any system)

Requires Python 3.10 or newer.

$ pip install -U streamlink

The same command updates Streamlink. On Linux, prefer a virtual environment or pipx install streamlink so you don't touch the system Python.

Check the installation

$ streamlink --version

If the command prints a version number, you're all set. In Launcher, Settings › Streamlink also shows the version it found.

Streamlink installed elsewhere? Launcher Chat

The apps look for Streamlink in the PATH and in the usual locations. If it is somewhere else, enter the path to streamlink.exe in Settings › Streamlink › Custom path (Launcher) or Settings › Watch (Chat).

05 · Get going

Getting started

Where to put the apps Launcher Chat

Download the file from the releases page (Launcher, Chat) and put it in a folder of your own, for example Documents\Streamlink. Settings are stored next to it, and the built-in update can replace the file. Avoid C:\Program Files, which is write-protected.

On Linux, make the AppImage executable, then run it:

$ chmod +x StreamlinkLauncher-*-x86_64.AppImage $ ./StreamlinkLauncher-*-x86_64.AppImage

For an entry in the applications menu, use a tool such as Gear Lever or AppImageLauncher.

Your first stream Launcher

  1. Make sure Streamlink and a video player are installed.
  2. Choose the platform with its pill: Twitch, Kick, YouTube, Dailymotion, Steam TV or Direct link.
  3. Type the channel name (eslcs) or paste a link (https://kick.com/…): a link selects the platform by itself.
  4. Choose the quality if needed, then Enter or Launch. The player opens after a few seconds.
  5. To follow or stop the stream, open the Log at the bottom of the window: it shows Streamlink's output and a Stop button.

Three faster ways Launcher

  • Copy a link: copy a stream's address, then switch back to the launcher. It offers to launch it, and the link is already in the mini bar. Can be turned off in Settings › Streamlink › Detect copied links.
  • Drag and drop (Windows): drag the address from the browser's address bar, selected text or a .url Internet shortcut onto the window.
  • Mini mode (Windows): Ctrl+Alt+S from any application, type, Enter.

Your first chat Chat

  1. Choose the platform with its pill, under the Add a chat field.
  2. Type the channel name or paste a link, then Enter. Ctrl+T puts the cursor in this field.
  3. The chat opens in a new tab, read-only. To write, connect your account (see Writing in chat).
  4. In the chat header, ▶ opens the stream with Streamlink and the link icon opens the channel in your browser.

The field accepts a name (eslcs), a prefix (kick:lunaria, steam:name) or a link: twitch.tv/…, kick.com/…, steam.tv/…, steamcommunity.com/broadcast/watch/…, “popout” links included. Your tabs come back at the next start.

07 · Every day

How do I manage history and favorites?

Add a favorite Launcher

  1. Choose the platform with its pill (Twitch, Kick…) and type the channel name.
  2. Click the Add a favorite card on the main screen.

The main screen shows the favorites of the selected platform, live ones first. See all opens the full list.

Launch, edit or remove a favorite Launcher

  • Launch: click its card.
  • More options: right-click the card, then Launch, Fill the field or Remove from favorites.
  • In the Favorites panel: clicking a row fills the field, ▶ launches, the trash can removes.

Who is live? Launcher

With Settings › Live › Check who is live, the launcher checks your Twitch and Kick favorites while it is open, every 2, 5, 10, 15 or 30 minutes (5 by default). Live previews adds the thumbnail, title and viewer count of live Twitch favorites, and Windows notification tells you when a favorite goes live: click the notification to watch.

History Launcher

  • The last 200 launches are kept. The most recent ones are shown under Recent; ▶ relaunches directly.
  • Full history opens the panel: a click fills the field, ▶ relaunches, the trash can deletes an entry, Clear all empties the history.
  • Suggestions in the input field come from your favorites, then your history: use ↓ ↑, then Enter.

Back up or copy to another PC Launcher

Settings › Backup › Export… saves your settings and favorites to a single file. Import… restores them and lets you choose: Yes adds the imported favorites to yours, No replaces your favorites, Cancel changes nothing. Paths specific to the computer (Streamlink, player, scripts) are not included, and neither is the history.

And in the chat? Chat

Streamlink Chat has no favorites: open chats come back by themselves at the next start. Close a chat with Ctrl+W or a middle click on its tab. To always open the same chats in one go, see the recipe Open your chats from a shortcut.

08 · Accounts

Writing in chat

Reading needs no account. To write, you need your own free application on each platform: that way, no secret ships with the program. You only do this once.

Connect Twitch Chat

  1. Open dev.twitch.tv/console/apps/create and log in with your Twitch account. Twitch may ask you to turn on two-factor authentication to use the console.
  2. Give the application a name, add the redirect URL http://localhost, choose the Chat Bot category and the Public client type, then create it.
  3. Copy its Client ID and paste it in Settings › Accounts (to write).
  4. Click Log in to Twitch. A twitch.tv/activate page opens: enter the code shown by the app and authorize it.
  5. The header of Twitch chats switches to Connected. The connection renews by itself.

The app only asks for two permissions: reading and writing in chat (chat:read, chat:edit).

Connect Kick Chat

  1. Open Kick's developer settings and create an application.
  2. Declare the redirect URL http://localhost:48125/callback and tick the read user info and write to chat scopes.
  3. Paste its Client ID and Client Secret in Settings › Accounts (to write).
  4. Click Log in to Kick: your browser opens on Kick, authorize the application. Kick sends you back to localhost:48125, where the app is waiting for the answer.

Port 48125 must be free while you log in. If another program uses it, close it while you connect.

Steam TV Chat

Steam doesn't allow writing in a broadcast chat from another program: Steam TV stays read-only, with no account.

Where are the tokens kept? Chat

  • In chat.json. On Windows, they are encrypted with DPAPI: only your Windows account, on this PC, can read them back.
  • On Linux, they are stored in plain text in your home folder. Don't share this file.
  • If you copy chat.json to another PC, the tokens can't be read there: log in again.

Log out and revoke access Chat

  • Log out, in Settings › Accounts, deletes the tokens from your PC.
  • To revoke access on Twitch's side too, open Settings › Connections on Twitch and disconnect your application.
  • On Kick's side, delete the application in the developer settings.

Formats, animations and cache Chat

10 · Recipes

Recipes to go faster

Choose the player for the ▶ button Chat

The chat starts Streamlink without any player option, so Streamlink uses the one from its configuration file, VLC by default. To switch to mpv, create this file (no extension) and add:

configplayer=mpv player-args=--force-window=immediate
SystemStreamlink configuration file
Windows%APPDATA%\streamlink\config
Linux~/.config/streamlink/config

If mpv isn't in the PATH, put its full path after player=. Launcher also uses this file when Settings › Video player is set to Default (Streamlink setting).

Watch with less delay

Streamlink has a low-latency mode for Twitch and Kick. The simplest way is to turn it on for one platform only, with a configuration file for its plugin, next to the config file:

config.twitchtwitch-low-latency
config.kickkick-low-latency

It works for both apps. The gain depends on the broadcaster, who must have enabled low latency; playback may buffer a little more often.

Record a stream while watching it

In a terminal, --record writes the stream to a file while you watch:

$ streamlink --record "{author}-{time:%Y%m%d-%H%M}.ts" https://www.twitch.tv/eslcs best

{author} becomes the channel name and {time:…} the date and time. Open the .ts file with VLC or mpv.

Launcher To do it from the launcher, add a dedicated platform to platforms.json (the Edit platforms.json link at the bottom of the settings), with a full path to your videos folder:

platforms.json (one more entry in the "platforms" list){ "id": "twitch-rec", "name": "Twitch REC", "input": "channel", "url": "https://www.twitch.tv/{arg}", "hosts": [], "args": ["--record", "C:\\Users\\you\\Videos\\{author}-{time:%Y%m%d-%H%M}.ts"], "qualities": ["best", "1080p60", "720p60", "480p"], "color": "#E91916", "text_color": "#FFFFFF", "live_check": "none" }

Restart the launcher: a Twitch REC pill appears. hosts stays empty so pasted Twitch links keep going to the regular Twitch pill. In JSON, each \ of a Windows path is written \\.

Never hit “quality not found”

Not every channel offers every quality. Launcher In the quality list, choose Custom… and enter a fallback list such as 720p60,720p,best: Streamlink takes the first one that exists, and the launcher remembers it for this platform. Chat The quality of the ▶ button is chosen from a fixed list; keep best if you watch very different channels.

Open your chats from a shortcut Chat

Streamlink Chat accepts chats as arguments. Create a Windows shortcut (right-click the desktop › New › Shortcut) with a target such as:

"C:\Users\you\Documents\Streamlink\StreamlinkChat.exe" --open twitch:eslcs --open kick:lunaria

If the chat is already open, these chats are added to the existing window. A channel link works as an argument too.

Tip: first rename the executable without a version number, for example StreamlinkChat.exe. A file named after its version changes name at each update, and the shortcut would no longer find it. A name without a version is kept.

Start the launcher minimized Launcher

Settings › Window and shortcut › Start with Windows starts it in the notification area. You can do the same with your own shortcut by adding --tray after the executable's path.

Keep your old .bat scripts Launcher

If you used to launch your streams with scripts, turn on Settings › Advanced › Show .bat scripts and choose the Scripts folder. A Scripts pill lists the .bat, .cmd, .ps1, .exe, .py and .lnk files in that folder. The field lets you pass an argument to the script (letters, digits, ., _ and - only).

11 · Updates

How do I update the app?

The launcher Launcher

  1. Open Settings › About: the card shows your version and the latest one published on GitHub.
  2. If a newer version exists, click Update. The launcher downloads the new .exe, checks its size and SHA-256 fingerprint, puts it in place of the old one and restarts.
  • Check for updates at start-up does the check by itself.
  • Update the launcher automatically also installs the new version at start-up, never during a stream.
  • A file named after its version (StreamlinkLauncher-1.4.2.exe) takes the new number; start with Windows follows the new name.

The chat Chat

Same idea in Settings › Updates: Check, then Update. The chat restarts with your open chats. A dot on the settings button signals a new version, and Automatic updates (off by default) does it all by itself at start-up.

AppImage or source: one-click update only applies to the Windows .exe placed in a writable folder (not C:\Program Files). With the AppImage, Update opens the release page: download the new AppImage and replace the old one. From source, run git pull.

Update Streamlink itself

The launcher compares your Streamlink version with the latest one published. If yours is older, the Settings › Streamlink card offers Update: with the Windows installer, it opens the download page; with pip, it copies the pip install -U streamlink command. With winget, Chocolatey, Scoop or your Linux distribution, use their usual update command (winget upgrade streamlink, for example).

12 · Settings

Other questions about settings

How do I choose my video player? Launcher

Settings › Video player: choose VLC, mpv, PotPlayer or another program, and enter its path if it isn't found. Player arguments adds options, for example --fullscreen. Default (Streamlink setting) lets Streamlink decide (see the recipe).

How do I change the default quality? Launcher Chat

In the launcher, the list next to the field remembers the quality per platform; Custom… accepts a specific quality or a fallback list. In the chat, it's Settings › Watch › Quality, used by the ▶ button.

How do I change the mini mode shortcut? Launcher

Settings › Window and shortcut: turn Global shortcut on or off and choose another combination than Ctrl+Alt+S. The shortcut's status is shown there.

Can the launcher keep running in the background? Launcher

Yes: with Minimize to the notification area, closing the window leaves the launcher next to the clock, with your streams and live monitoring. Right-click the icon to reopen the window, open mini mode, launch a live favorite or Quit. Start with Windows starts it minimized.

How do I turn off copied-link detection? Launcher

Uncheck Detect copied links in Settings › Streamlink. The clipboard is only read on your computer; nothing is saved or sent.

Can I remove the platform colors? Launcher Chat

Yes: Platform colors in Settings › General (Launcher) or Settings › Display (Chat).

How do I add a platform? Launcher

The Edit platforms.json link, at the bottom of the settings panel, opens the file. Each entry gives:

  • id and name: a unique identifier and the pill's name;
  • input: channel, youtube, video, url (any link) or none (nothing to type);
  • url: the address template, where {arg} is replaced by what you type;
  • hosts: the domains that select this pill when you paste a link;
  • args: extra Streamlink options;
  • qualities, color, text_color;
  • live_check: twitch, streamlink or none.

Save, then restart the launcher to see the new pill. A complete example is in the Record a stream recipe.

How do I write in a chat? Chat

Connect your Twitch or Kick account in Settings › Accounts (to write). The steps are detailed in Writing in chat.

What display settings does the chat offer? Chat

Settings › Display: language, theme, text size, message time, badges, animated emotes, platform colors and number of messages kept per chat (500, 1000, 2000 or 5000). Emotes turns BetterTTV, FrankerFaceZ and 7TV on or off. Mentions highlights messages that mention your username or words of your choice, separated by commas.

14 · Troubleshooting

Troubleshooting (FAQ)

“Streamlink not found” Launcher Chat

Install Streamlink (see Installing Streamlink), then restart the app. If it is installed elsewhere, enter the path to streamlink.exe in Settings. Check in a terminal that streamlink --version answers.

The stream doesn't start Launcher

Open the log drawer at the bottom of the window: Streamlink's error message is shown there. The most common causes:

  • No playable streams found: the channel is offline, or the name is misspelled.
  • The requested quality doesn't exist for this stream: choose best or a fallback list with Custom….
  • The video player isn't found: enter its path in Settings › Video player.
The stream stutters or cuts out Launcher Chat

Try a lower quality (720p, 480p): it needs less bandwidth. If you turned on low latency, remove it. The log messages tell you whether Streamlink is waiting for data.

There is sound, but no picture Launcher

Check that the chosen quality isn't audio_only. Otherwise, update your player; with mpv, the --force-window=immediate option opens the window right away.

Windows shows “Windows protected your PC” Launcher Chat

The executables aren't code-signed yet, so SmartScreen warns on first launch. This is not a detection.

  1. Check the file: in PowerShell, Get-FileHash .\StreamlinkLauncher-1.5.2.exe, and compare with the release's SHA256SUMS.txt.
  2. Click More info, then Run anyway.
  3. If nothing happens on double-click: right-click › Properties › tick Unblock, or Unblock-File .\StreamlinkLauncher-1.5.2.exe.
My antivirus blocks or deletes the exe Launcher Chat

Programs built with PyInstaller are sometimes flagged by mistake. Check the SHA-256, restore the file from quarantine, add its folder to the exclusions, and report the false positive (Microsoft Defender: submit a file, category Incorrectly detected as malware). You can also run the app from source.

Ctrl+Alt+S does nothing Launcher

Another application probably uses this shortcut. The launcher warns you at start-up; choose another one in Settings › Window and shortcut. Every key press received is noted in the log. The global shortcut only exists on Windows.

The app won't open a second time Launcher Chat

That's by design: only one copy of each app runs at a time. The launcher is probably in the notification area, next to the clock. For the chat, opening it again sends its chats to the window that is already open.

“The launcher folder is read-only” Launcher

The launcher can't write next to its .exe (for example in C:\Program Files). It then stores its data in %APPDATA%\Streamlink Launcher. Everything works, but the built-in update won't be able to replace the file: move it to a folder of your own.

The AppImage won't start Launcher Chat
  • Make it executable: chmod +x followed by the file name.
  • Message about FUSE: install libfuse2, or run it with --appimage-extract-and-run.
  • Error about GLIBC: your system is too old (glibc 2.35 minimum). Run the app from source.
A Kick chat stays in error Chat

Kick changed its chat system on October 13, 2026 and doesn't document it: support is experimental, and Kick's anti-bot protection can block some requests (Kick is blocking the request). Right-click the tab › Reconnect, or close and reopen the chat. If the error persists, open an issue with chat.log.

“Channel not found” Chat

Check the spelling and the selected platform: a name typed alone goes to the selected pill. Paste the channel's link instead, which selects the platform by itself.

The Steam TV chat stays empty Chat

The chat only exists during a broadcast. While offline, Streamlink Chat checks again every 30 seconds and shows messages as soon as the broadcast starts.

I can't write in the chat Chat

You need to connect your account (see Writing in chat). Steam TV stays read-only. On Twitch, also check that you aren't banned from the chat and that the room isn't subscribers-only.

The Kick login doesn't complete Chat
  • Check that your Kick application's redirect URL is exactly http://localhost:48125/callback.
  • Check the Client ID and Client Secret (no extra spaces).
  • Port 48125 must be free, and your firewall must not block local connections.
I have to log in again after changing PC Chat

That's expected: on Windows, tokens are encrypted for your account on this PC. Copied elsewhere, they can't be read. Log in again in Settings › Accounts.

Some emotes show as text Chat

Tk only displays PNG and GIF. An emote offered only as WebP or AVIF stays as text. Also check that its provider (BetterTTV, FrankerFaceZ, 7TV) is on in Settings › Emotes, and that it is available for this platform (see Emotes and platforms).

The chat uses a lot of memory Chat

Animated emotes are the most costly. Since 0.2.1, they only animate in the displayed chat and the cache is capped. You can lower memory further by turning off Animated emotes or keeping 500 messages per chat (Settings › Display).

The built-in update fails Launcher Chat

The app must be able to replace its own file: put the .exe in a folder of your own (for example Documents\Streamlink), not in C:\Program Files. If it fails, the old version is put back; you can always download the new one from the releases page.

A settings file is damaged Launcher Chat

At start-up, the app tries its .bak copy and, for the launcher, sets the damaged file aside as .corrupt and warns you. To start from scratch, close the app and rename the file in question: it will be recreated with the default settings.

No results. Try another word, or ask your question on GitHub.

15 · Uninstalling

Uninstall cleanly

The apps don't install anything: deleting their files is enough. A few precautions avoid leftovers.

The launcher on Windows Launcher

  1. If Start with Windows is on, turn it off first in Settings › Window and shortcut.
  2. Note where your data is: Settings › About › Open the data folder. If you want to keep your favorites, do an Export….
  3. Quit the launcher: right-click its icon near the clock › Quit.
  4. Delete the .exe, then the data folder (config.json, platforms.json, streams/, launcher.log and the .bak files), next to the .exe or in %APPDATA%\Streamlink Launcher.

Already deleted without turning off start-up? Disable the entry in Task Manager › Startup apps, or delete the StreamlinkLauncher value from HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

The chat on Windows Chat

  1. In Settings › Accounts, click Log out for each account, then revoke access on Twitch's or Kick's side if you wish (see Writing in chat).
  2. Close the chat.
  3. Delete the .exe, chat.json and its .bak, the cache/ folder and chat.log, next to the .exe or in %APPDATA%\Streamlink Chat.

On Linux Launcher Chat

Delete the AppImage, then the data folders:

$ rm -r ~/.config/streamlink-launcher ~/.config/streamlink-chat

If you created a menu entry with Gear Lever or AppImageLauncher, remove it from that tool.

What about Streamlink?

It is uninstalled separately, the way you installed it: Windows Settings › Apps for the installer, winget uninstall streamlink, pip uninstall streamlink or your distribution's package manager. Its configuration file is in %APPDATA%\streamlink or ~/.config/streamlink.

16 · Community

Report a bug and contribute

Before opening an issue

  • Update the app: only the latest version receives fixes.
  • Search the existing issues (Launcher, Chat): the problem may already be known.
  • Read through Troubleshooting.

What to include

  • The app and its version (Settings › About or Settings › Updates).
  • Your system (Windows 11, Ubuntu 24.04…) and the kind of install: .exe, AppImage or source.
  • The Streamlink version: streamlink --version.
  • What you did, what you expected and what happened. For a chat, the platform and the channel.
  • The log: launcher.log or chat.log (and .log.1 if it exists), in the data folder. For a stream that won't start, also copy the text of the log drawer.

Read the log before sending it. It may contain channel names or paths from your PC; remove anything you don't want to make public.

Then open an issue: Launcher or Chat.

A security vulnerability?

Do not open a public issue. Use GitHub's private form (Launcher, Chat) with the version, the steps to reproduce and the impact. You'll get an answer within about a week.

Contribute

Bug reports, translations and pull requests are welcome.

  1. For anything bigger than a small fix, open an issue first to discuss it.
  2. All you need is Python 3.10 or newer, with no third-party dependency. Tkinter is needed for the interface.
  3. Run the checks before the pull request:
$ python -m unittest discover -s tests -v $ python -m pip install ruff && python -m ruff check . $ xvfb-run -a python -m unittest tests.test_gui
  • Add a line under Unreleased in CHANGELOG.md, in both English and French.
  • Releases are published by the maintainer.

Translate the apps

Texts live in lang/*.json, one file per language (fr, en, es, de, it). Every language must have exactly the same keys: a test checks it. For a new language, copy en.json, translate the values without touching the keys or the {variables}, and keep texts short, especially in the launcher.

17 · Vocabulary

Glossary

#ABCDEFGHILMNOPQRSTW
7TV
Third-party emote service, often animated, for Twitch and Kick.
.bak
Copy of the previous version of a settings file, used to recover it if it gets damaged.
AppImage
Single-file Linux application format, with nothing to install. The apps' AppImages bundle their own Python.
Badge
Small icon in front of a username: broadcaster, moderator, VIP, subscriber…
BetterTTV (BTTV)
Popular extension that adds emotes to Twitch chats.
Centrifugo
Real-time messaging system used by Kick's chat since October 2026.
Client ID, Client Secret
Identifier (public) and password (secret) of the application you create on Twitch or Kick to write in chat.
Device code
Twitch's login method: the app shows a code, you enter it on twitch.tv/activate.
DPAPI
Windows encryption feature: only your account, on your PC, can read back what it protects. It protects the chat's tokens.
Direct link
Launcher pill that accepts any link Streamlink supports.
Emote
Small image used like a word in chat, for example KEKW.
Fallback list
Several qualities separated by commas: Streamlink takes the first one available.
False positive
A safe file wrongly flagged by an antivirus.
Favorite
Channel saved in the launcher, launched in one click, with its live status.
FrankerFaceZ (FFZ)
Another emote extension for Twitch.
FUSE
Linux component that lets an AppImage run without being extracted. Package libfuse2.
glibc
Core library of Linux systems. The AppImages need version 2.35 or newer.
HLS
Streaming format cut into small segments, used by Twitch and Kick.
IRC
Old chat protocol that Twitch's chat is built on.
Latency
Delay between what happens on the broadcaster's side and what you see.
Log
The drawer at the bottom of the launcher, and the launcher.log and chat.log files that record errors.
Mention
Message that mentions your username or a word you chose. It is highlighted.
Mini mode
The launcher's floating bar, opened by a global shortcut, to launch a stream without opening the window.
Notification area
The icons next to the Windows clock. The launcher can keep running there with its window closed.
OAuth
Standard way to let an app act on your behalf without giving it your password.
PATH
List of folders where the system looks for programs. Streamlink's installer adds it there.
platforms.json
Launcher file that describes the platforms: address, options, qualities, color, live status.
Player
Program that displays the video sent by Streamlink: VLC, mpv, PotPlayer…
Plugin
Part of Streamlink that knows how to read a given site (twitch, kick, steam…).
Portable
An app that keeps its settings next to its file: you can move it or copy it to a USB stick.
Pusher
Kick chat's old real-time system, kept as a fallback.
PyInstaller
Tool that turns a Python program into a single .exe.
Quality
Stream resolution requested from Streamlink: best, 1080p60, audio_only…
Read-only
A chat you can read but not write in: with no account connected, or always on Steam TV.
Release
Version published on GitHub, with its files to download and SHA256SUMS.txt.
SHA-256
A file's fingerprint. If it matches the release's, the file hasn't been altered.
SmartScreen
Windows protection that warns on the first launch of a recent or unsigned program.
Streamlink
Free program that fetches a stream and sends it to your player. Both apps rely on it.
Token
Temporary key that Twitch or Kick gives the app after you log in. It replaces your password, which the app never sees.
WebSocket
Connection that stays open between the app and the server to receive messages as they arrive.
