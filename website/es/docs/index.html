01 · Presentación

¿Qué son Streamlink Launcher y Streamlink Chat?

Launcher

Una interfaz ligera para Streamlink. Escribe el nombre de un canal o pega un enlace, pulsa Intro y el stream se abre en tu reproductor de vídeo (VLC, mpv, PotPlayer…) en lugar del navegador. Recuerda tus favoritos, te dice cuáles están en directo y abre una barra mini con Ctrl+Alt+S.

Chat

El compañero del lanzador, al estilo de Chatterino: los chats de Twitch, Kick y Steam TV en una sola ventana, una pestaña por chat, cada una con el color de su plataforma. Lectura sin cuenta, escritura en Twitch y Kick tras iniciar sesión, y ▶ para abrir el stream con Streamlink.

Plataformas compatibles

PlataformaLauncherChat
TwitchSí, sin anunciosLectura y escritura
KickSíLectura y escritura (experimental)
Steam TVSíSolo lectura
YouTube, DailymotionSíNo
Enlace directoCualquier sitio compatible con StreamlinkNo

Requisitos

  • Windows 10 u 11: un .exe de un solo archivo, sin instalación.
  • Linux x86_64: una AppImage que incluye su propio Python. Necesita glibc 2.35 o posterior (Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 o posteriores).
  • Desde el código fuente: Python 3.10 o posterior con Tcl/Tk, sin ninguna otra dependencia.
  • Para ver streams: Streamlink y un reproductor de vídeo, VLC por defecto.

En Linux, el lanzador no tiene icono en el área de notificación, atajo global, inicio con el sistema, arrastrar y soltar, notificaciones de directos, vistas previas de los streams ni actualización integrada.

Idiomas

Las dos aplicaciones están disponibles en inglés, francés, español, alemán e italiano. Siguen el idioma del sistema; puedes cambiarlo en Ajustes › General (Launcher) o Ajustes › Visualización (Chat).

03 · El motor

¿Qué es Streamlink?

Streamlink es un programa libre de línea de comandos. Recupera el flujo de vídeo de un stream y lo envía a tu reproductor. Así ves Twitch, Kick o YouTube en VLC o mpv, sin la página web alrededor: menos memoria, sin anuncios de Twitch y con los atajos de tu propio reproductor.

Normalmente, Streamlink se usa en un terminal:

$ streamlink https://www.twitch.tv/eslcs best

Streamlink Launcher escribe este comando por ti: reconoce la plataforma, añade las opciones adecuadas y la calidad elegida, y luego inicia Streamlink. Streamlink Chat lo usa para su botón ▶.

Calidades

best elige la calidad más alta, worst la más baja y audio_only solo el sonido (Twitch). También puedes pedir una calidad concreta, como 1080p60, o una lista de alternativas: 720p60,720p,best toma la primera disponible.

¿Y los anuncios de Twitch?

Desde la versión 7.5.0, Streamlink siempre filtra los anuncios de los streams de Twitch. La antigua opción --twitch-disable-ads ya no es necesaria (está obsoleta, pero se sigue aceptando).

Streamlink es un proyecto independiente. Ninguna de las dos aplicaciones lo incluye: se instala por separado, una sola vez.

04 · Instalación

¿Dónde descargar Streamlink y cómo instalarlo?

Streamlink está disponible en su sitio oficial, streamlink.github.io/install. Elige tu sistema:

Windows: el instalador (recomendado)

  1. Abre la página de versiones de Streamlink para Windows.
  2. Descarga el instalador .exe de la última versión (Windows 10 o posterior, x86_64).
  3. Ejecútalo y sigue los pasos. Añade Streamlink al PATH: el lanzador lo encuentra solo.

O con un gestor de paquetes

# winget (incluido en Windows 11) > winget install streamlink # Chocolatey > choco install streamlink # Scoop > scoop bucket add extras > scoop install streamlink

Linux: el paquete de tu distribución

# Fedora $ sudo dnf install streamlink # Arch Linux $ sudo pacman -S streamlink # Debian testing / sid $ sudo apt update && sudo apt install streamlink

Ubuntu y derivadas: el sitio de Streamlink desaconseja el paquete de Ubuntu, que no está mantenido. Usa la instalación con Python (siguiente pestaña) o la AppImage de Streamlink, que se ofrece en la misma página.

También necesitas un reproductor, por ejemplo sudo apt install mpv o sudo dnf install vlc.

Con Python (cualquier sistema)

Requiere Python 3.10 o posterior.

$ pip install -U streamlink

El mismo comando actualiza Streamlink. En Linux, es preferible un entorno virtual o pipx install streamlink para no tocar el Python del sistema.

Comprobar la instalación

$ streamlink --version

Si el comando muestra un número de versión, todo está listo. En Launcher, Ajustes › Streamlink también muestra la versión encontrada.

¿Streamlink instalado en otro sitio? Launcher Chat

Las aplicaciones buscan Streamlink en el PATH y en las ubicaciones habituales. Si está en otro lugar, indica la ruta de streamlink.exe en Ajustes › Streamlink › Ruta personalizada (Launcher) o en Ajustes › Ver (Chat).

05 · Empezar

Primeros pasos

Dónde colocar las aplicaciones Launcher Chat

Descarga el archivo desde la página de versiones (Launcher, Chat) y colócalo en una carpeta tuya, por ejemplo Documents\Streamlink. Los ajustes se guardan junto a él y la actualización integrada puede sustituir el archivo. Evita C:\Program Files, que está protegida contra escritura.

En Linux, haz ejecutable la AppImage y luego iníciala:

$ chmod +x StreamlinkLauncher-*-x86_64.AppImage $ ./StreamlinkLauncher-*-x86_64.AppImage

Para tener una entrada en el menú de aplicaciones, usa una herramienta como Gear Lever o AppImageLauncher.

Tu primer stream Launcher

  1. Comprueba que Streamlink y un reproductor de vídeo están instalados.
  2. Elige la plataforma con su pastilla: Twitch, Kick, YouTube, Dailymotion, Steam TV o Enlace directo.
  3. Escribe el nombre del canal (eslcs) o pega un enlace (https://kick.com/…): un enlace selecciona la plataforma por sí solo.
  4. Elige la calidad si hace falta y pulsa Intro o Iniciar. El reproductor se abre al cabo de unos segundos.
  5. Para seguir o detener el stream, abre el Registro en la parte inferior de la ventana: muestra la salida de Streamlink y un botón Detener.

Tres formas más rápidas Launcher

  • Copiar un enlace: copia la dirección de un stream y vuelve al lanzador. Te propone iniciarlo, y el enlace ya está en la barra mini. Se puede desactivar en Ajustes › Streamlink › Detectar enlaces copiados.
  • Arrastrar y soltar (Windows): arrastra a la ventana la dirección desde la barra del navegador, un texto seleccionado o un acceso directo de Internet .url.
  • Modo mini (Windows): Ctrl+Alt+S desde cualquier aplicación, escribe e Intro.

Tu primer chat Chat

  1. Elige la plataforma con su pastilla, debajo del campo Añadir un chat.
  2. Escribe el nombre del canal o pega un enlace y pulsa Intro. Ctrl+T coloca el cursor en este campo.
  3. El chat se abre en una pestaña nueva, en solo lectura. Para escribir, conecta tu cuenta (consulta Escribir en el chat).
  4. En la cabecera del chat, ▶ abre el stream con Streamlink y el icono de enlace abre el canal en tu navegador.

El campo acepta un nombre (eslcs), un prefijo (kick:lunaria, steam:nombre) o un enlace: twitch.tv/…, kick.com/…, steam.tv/…, steamcommunity.com/broadcast/watch/…, incluidos los enlaces «popout». Tus pestañas vuelven en el siguiente inicio.

07 · Día a día

¿Cómo gestiono el historial y los favoritos?

Añadir un favorito Launcher

  1. Elige la plataforma con su pastilla (Twitch, Kick…) y escribe el nombre del canal.
  2. Haz clic en la tarjeta Añadir a favoritos de la pantalla principal.

La pantalla principal muestra los favoritos de la plataforma seleccionada, primero los que están en directo. Ver todo abre la lista completa.

Iniciar, editar o quitar un favorito Launcher

  • Iniciar: haz clic en su tarjeta.
  • Más opciones: clic derecho en la tarjeta y luego Iniciar, Rellenar el campo o Quitar de favoritos.
  • En el panel Favoritos: un clic en una fila rellena el campo, ▶ inicia y la papelera quita.

¿Quién está en directo? Launcher

Con Ajustes › En directo › Comprobar quién está en directo, el lanzador revisa tus favoritos de Twitch y Kick mientras está abierto, cada 2, 5, 10, 15 o 30 minutos (5 por defecto). Vista previa de los directos añade la miniatura, el título y el número de espectadores de los favoritos de Twitch en directo, y Notificación de Windows te avisa cuando un favorito empieza un directo: haz clic en la notificación para verlo.

Historial Launcher

  • Se guardan los últimos 200 lanzamientos. Los más recientes aparecen en Recientes; ▶ los vuelve a iniciar directamente.
  • Historial completo abre el panel: un clic rellena el campo, ▶ vuelve a iniciar, la papelera borra una entrada y Borrar todo vacía el historial.
  • Las sugerencias del campo de entrada vienen de tus favoritos y luego de tu historial: usa ↓ ↑ y después Intro.

Hacer una copia o pasar a otro PC Launcher

Ajustes › Copia de seguridad › Exportar… guarda tus ajustes y favoritos en un único archivo. Importar… los restaura y te deja elegir: Sí añade los favoritos importados a los tuyos, No sustituye tus favoritos y Cancelar no cambia nada. Las rutas propias del equipo (Streamlink, reproductor, scripts) no se incluyen, ni tampoco el historial.

¿Y en el chat? Chat

Streamlink Chat no tiene favoritos: los chats abiertos vuelven solos en el siguiente inicio. Cierra un chat con Ctrl+W o con un clic central en su pestaña. Para abrir siempre los mismos chats de una vez, consulta la receta Abrir tus chats desde un acceso directo.

08 · Cuentas

Escribir en el chat

Leer no requiere cuenta. Para escribir, necesitas tu propia aplicación gratuita en cada plataforma: así, ningún secreto viaja con el programa. Solo se hace una vez.

Conectar Twitch Chat

  1. Abre dev.twitch.tv/console/apps/create e inicia sesión con tu cuenta de Twitch. Es posible que Twitch te pida activar la verificación en dos pasos para usar la consola.
  2. Ponle un nombre a la aplicación, añade la URL de redirección http://localhost, elige la categoría Chat Bot y el tipo de cliente Public y créala.
  3. Copia su Client ID y pégalo en Ajustes › Cuentas (para escribir).
  4. Haz clic en Iniciar sesión en Twitch. Se abre una página twitch.tv/activate: introduce el código que muestra la aplicación y autorízala.
  5. La cabecera de los chats de Twitch pasa a Conectado. La conexión se renueva sola.

La aplicación solo pide dos permisos: leer y escribir en el chat (chat:read, chat:edit).

Conectar Kick Chat

  1. Abre los ajustes de desarrollador de Kick y crea una aplicación.
  2. Declara la URL de redirección http://localhost:48125/callback y marca los permisos read user info y write to chat.
  3. Pega su Client ID y su Client Secret en Ajustes › Cuentas (para escribir).
  4. Haz clic en Iniciar sesión en Kick: tu navegador se abre en Kick, autoriza la aplicación. Kick te devuelve a localhost:48125, donde la aplicación espera la respuesta.

El puerto 48125 debe estar libre durante el inicio de sesión. Si otro programa lo usa, ciérralo mientras te conectas.

Steam TV Chat

Steam no permite escribir en el chat de una emisión desde otro programa: Steam TV se queda en solo lectura, sin cuenta.

¿Dónde se guardan los tokens? Chat

  • En chat.json. En Windows se cifran con DPAPI: solo tu cuenta de Windows, en este PC, puede volver a leerlos.
  • En Linux se guardan sin cifrar en tu carpeta personal. No compartas este archivo.
  • Si copias chat.json a otro PC, los tokens no se podrán leer allí: vuelve a iniciar sesión.

Cerrar sesión y revocar el acceso Chat

  • Cerrar sesión, en Ajustes › Cuentas, borra los tokens de tu PC.
  • Para revocar también el acceso en Twitch, abre Configuración › Conexiones en Twitch y desconecta tu aplicación.
  • En Kick, borra la aplicación en los ajustes de desarrollador.

10 · Recetas

Recetas para ir más rápido

Elegir el reproductor del botón ▶ Chat

El chat inicia Streamlink sin ninguna opción de reproductor, así que Streamlink usa el de su archivo de configuración, VLC por defecto. Para pasar a mpv, crea este archivo (sin extensión) y añade:

configplayer=mpv player-args=--force-window=immediate
SistemaArchivo de configuración de Streamlink
Windows%APPDATA%\streamlink\config
Linux~/.config/streamlink/config

Si mpv no está en el PATH, pon su ruta completa después de player=. Launcher también usa este archivo cuando Ajustes › Reproductor de vídeo está en Predeterminado (ajuste de Streamlink).

Ver con menos retraso

Streamlink tiene un modo de baja latencia para Twitch y Kick. Lo más sencillo es activarlo solo para una plataforma, con un archivo de configuración para su plugin, junto al archivo config:

config.twitchtwitch-low-latency
config.kickkick-low-latency

Funciona con las dos aplicaciones. La mejora depende del emisor, que debe haber activado la baja latencia; la reproducción puede cargar un poco más a menudo.

Grabar un stream mientras lo ves

En un terminal, --record escribe el stream en un archivo mientras lo ves:

$ streamlink --record "{author}-{time:%Y%m%d-%H%M}.ts" https://www.twitch.tv/eslcs best

{author} se convierte en el nombre del canal y {time:…} en la fecha y la hora. Abre el archivo .ts con VLC o mpv.

Launcher Para hacerlo desde el lanzador, añade una plataforma dedicada en platforms.json (el enlace Editar platforms.json al final de los ajustes), con una ruta completa a tu carpeta de vídeos:

platforms.json (una entrada más en la lista "platforms"){ "id": "twitch-rec", "name": "Twitch REC", "input": "channel", "url": "https://www.twitch.tv/{arg}", "hosts": [], "args": ["--record", "C:\\Users\\tu\\Videos\\{author}-{time:%Y%m%d-%H%M}.ts"], "qualities": ["best", "1080p60", "720p60", "480p"], "color": "#E91916", "text_color": "#FFFFFF", "live_check": "none" }

Reinicia el lanzador: aparece una pastilla Twitch REC. hosts se queda vacío para que los enlaces de Twitch pegados sigan yendo a la pastilla Twitch normal. En JSON, cada \ de una ruta de Windows se escribe \\.

No volver a ver «calidad no encontrada»

No todos los canales ofrecen todas las calidades. Launcher En la lista de calidades, elige Personalizada… e introduce una lista de alternativas como 720p60,720p,best: Streamlink toma la primera que exista y el lanzador la recuerda para esta plataforma. Chat La calidad del botón ▶ se elige en una lista fija; deja best si ves canales muy distintos.

Abrir tus chats desde un acceso directo Chat

Streamlink Chat acepta chats como argumentos. Crea un acceso directo de Windows (clic derecho en el escritorio › Nuevo › Acceso directo) con un destino como:

"C:\Users\tu\Documents\Streamlink\StreamlinkChat.exe" --open twitch:eslcs --open kick:lunaria

Si el chat ya está abierto, estos chats se añaden a la ventana existente. Un enlace de canal también sirve como argumento.

Consejo: primero cambia el nombre del ejecutable para quitarle el número de versión, por ejemplo StreamlinkChat.exe. Un archivo que lleva su versión en el nombre cambia de nombre en cada actualización y el acceso directo dejaría de encontrarlo. Un nombre sin versión se conserva.

Iniciar el lanzador minimizado Launcher

Ajustes › Ventana y atajo › Iniciar con Windows lo arranca en el área de notificación. Puedes hacer lo mismo con tu propio acceso directo añadiendo --tray después de la ruta del ejecutable.

Conservar tus antiguos scripts .bat Launcher

Si antes iniciabas tus streams con scripts, activa Ajustes › Avanzado › Mostrar los scripts .bat y elige la Carpeta de scripts. Una pastilla Scripts lista los archivos .bat, .cmd, .ps1, .exe, .py y .lnk de esa carpeta. El campo permite pasar un argumento al script (solo letras, cifras, ., _ y -).

11 · Actualizaciones

¿Cómo actualizo la aplicación?

El lanzador Launcher

  1. Abre Ajustes › Acerca de: la tarjeta muestra tu versión y la última publicada en GitHub.
  2. Si hay una versión más reciente, haz clic en Actualizar. El lanzador descarga el nuevo .exe, comprueba su tamaño y su huella SHA-256, lo pone en lugar del antiguo y se reinicia.
  • Buscar actualizaciones al iniciar hace la comprobación por sí solo.
  • Actualizar el lanzador automáticamente también instala la nueva versión al iniciar, nunca durante un stream.
  • Un archivo que lleva su versión en el nombre (StreamlinkLauncher-1.4.2.exe) toma el nuevo número; el inicio con Windows sigue el nuevo nombre.

El chat Chat

La misma idea en Ajustes › Actualizaciones: Comprobar y luego Actualizar. El chat se reinicia con tus chats abiertos. Un punto en el botón de ajustes señala una nueva versión, y Actualizaciones automáticas (desactivado por defecto) lo hace todo solo al iniciar.

AppImage o código fuente: la actualización con un clic solo se aplica al .exe de Windows colocado en una carpeta con permiso de escritura (no en C:\Program Files). Con la AppImage, Actualizar abre la página de la versión: descarga la nueva AppImage y sustituye la antigua. Desde el código fuente, ejecuta git pull.

Actualizar el propio Streamlink

El lanzador compara tu versión de Streamlink con la última publicada. Si la tuya es más antigua, la tarjeta Ajustes › Streamlink ofrece Actualizar: con el instalador de Windows, abre la página de descarga; con pip, copia el comando pip install -U streamlink. Con winget, Chocolatey, Scoop o tu distribución de Linux, usa su comando de actualización habitual (winget upgrade streamlink, por ejemplo).

12 · Ajustes

Otras preguntas sobre los ajustes

¿Cómo elijo mi reproductor de vídeo? Launcher

Ajustes › Reproductor de vídeo: elige VLC, mpv, PotPlayer u otro programa, e indica su ruta si no se encuentra. Argumentos del reproductor añade opciones, por ejemplo --fullscreen. Predeterminado (ajuste de Streamlink) deja que decida Streamlink (consulta la receta).

¿Cómo cambio la calidad por defecto? Launcher Chat

En el lanzador, la lista junto al campo recuerda la calidad por plataforma; Personalizada… acepta una calidad concreta o una lista de alternativas. En el chat, es Ajustes › Ver › Calidad, que usa el botón ▶.

¿Cómo cambio el atajo del modo mini? Launcher

Ajustes › Ventana y atajo: activa o desactiva Atajo global y elige otra combinación distinta de Ctrl+Alt+S. Allí se muestra el estado del atajo.

¿Puede el lanzador seguir funcionando en segundo plano? Launcher

Sí: con Minimizar al área de notificación, cerrar la ventana deja el lanzador junto al reloj, con tus streams y la vigilancia de directos. Clic derecho en el icono para volver a abrir la ventana, abrir el modo mini, iniciar un favorito en directo o Salir. Iniciar con Windows lo arranca minimizado.

¿Cómo desactivo la detección de enlaces copiados? Launcher

Desmarca Detectar enlaces copiados en Ajustes › Streamlink. El portapapeles solo se lee en tu equipo; no se guarda ni se envía nada.

¿Puedo quitar los colores de las plataformas? Launcher Chat

Sí: Colores por plataforma en Ajustes › General (Launcher) o Ajustes › Visualización (Chat).

¿Cómo añado una plataforma? Launcher

El enlace Editar platforms.json, al final del panel de ajustes, abre el archivo. Cada entrada indica:

  • id y name: un identificador único y el nombre de la pastilla;
  • input: channel, youtube, video, url (cualquier enlace) o none (nada que escribir);
  • url: la plantilla de la dirección, donde {arg} se sustituye por lo que escribes;
  • hosts: los dominios que seleccionan esta pastilla al pegar un enlace;
  • args: opciones adicionales de Streamlink;
  • qualities, color, text_color;
  • live_check: twitch, streamlink o none.

Guarda y reinicia el lanzador para ver la nueva pastilla. Hay un ejemplo completo en la receta Grabar un stream.

¿Cómo escribo en un chat? Chat

Conecta tu cuenta de Twitch o Kick en Ajustes › Cuentas (para escribir). Los pasos se detallan en Escribir en el chat.

¿Qué ajustes de visualización ofrece el chat? Chat

Ajustes › Visualización: idioma, tema, tamaño del texto, hora de los mensajes, insignias, emotes animados, colores por plataforma y número de mensajes guardados por chat (500, 1000, 2000 o 5000). Emotes activa o desactiva BetterTTV, FrankerFaceZ y 7TV. Menciones resalta los mensajes que mencionan tu nombre o las palabras que elijas, separadas por comas.

14 · Solución de problemas

Solución de problemas (FAQ)

«Streamlink no encontrado» Launcher Chat

Instala Streamlink (consulta Instalar Streamlink) y reinicia la aplicación. Si está instalado en otro sitio, indica la ruta de streamlink.exe en los ajustes. Comprueba en un terminal que streamlink --version responde.

El stream no arranca Launcher

Abre el panel de registro en la parte inferior de la ventana: ahí aparece el mensaje de error de Streamlink. Las causas más habituales:

  • No playable streams found: el canal no está emitiendo o el nombre está mal escrito.
  • La calidad pedida no existe para este stream: elige best o una lista de alternativas con Personalizada….
  • No se encuentra el reproductor de vídeo: indica su ruta en Ajustes › Reproductor de vídeo.
El stream se entrecorta o se corta Launcher Chat

Prueba una calidad más baja (720p, 480p): necesita menos ancho de banda. Si activaste la baja latencia, quítala. Los mensajes del registro indican si Streamlink está esperando datos.

Hay sonido, pero no imagen Launcher

Comprueba que la calidad elegida no es audio_only. Si no, actualiza tu reproductor; con mpv, la opción --force-window=immediate abre la ventana enseguida.

Windows muestra «Windows protegió su PC» Launcher Chat

Los ejecutables todavía no tienen firma de código, así que SmartScreen avisa en el primer inicio. No es una detección.

  1. Comprueba el archivo: en PowerShell, Get-FileHash .\StreamlinkLauncher-1.5.1.exe, y compáralo con el SHA256SUMS.txt de la versión.
  2. Haz clic en Más información y luego en Ejecutar de todas formas.
  3. Si no pasa nada al hacer doble clic: clic derecho › Propiedades › marca Desbloquear, o Unblock-File .\StreamlinkLauncher-1.5.1.exe.
Mi antivirus bloquea o borra el exe Launcher Chat

Los programas creados con PyInstaller a veces se marcan por error. Comprueba el SHA-256, restaura el archivo desde la cuarentena, añade su carpeta a las exclusiones y notifica el falso positivo (Microsoft Defender: enviar un archivo, categoría Incorrectly detected as malware). También puedes ejecutar la aplicación desde el código fuente.

Ctrl+Alt+S no hace nada Launcher

Probablemente otra aplicación usa este atajo. El lanzador te avisa al iniciar; elige otro en Ajustes › Ventana y atajo. Cada pulsación recibida queda anotada en el registro. El atajo global solo existe en Windows.

La aplicación no se abre una segunda vez Launcher Chat

Es intencionado: solo se ejecuta una copia de cada aplicación a la vez. El lanzador probablemente está en el área de notificación, junto al reloj. En el caso del chat, abrirlo de nuevo envía sus chats a la ventana ya abierta.

«La carpeta del lanzador está protegida contra escritura» Launcher

El lanzador no puede escribir junto a su .exe (por ejemplo, en C:\Program Files). Entonces guarda sus datos en %APPDATA%\Streamlink Launcher. Todo funciona, pero la actualización integrada no podrá sustituir el archivo: muévelo a una carpeta tuya.

La AppImage no arranca Launcher Chat
  • Hazla ejecutable: chmod +x seguido del nombre del archivo.
  • Mensaje sobre FUSE: instala libfuse2 o iníciala con --appimage-extract-and-run.
  • Error sobre GLIBC: tu sistema es demasiado antiguo (glibc 2.35 como mínimo). Ejecuta la aplicación desde el código fuente.
Un chat de Kick se queda en error Chat

Kick cambió su sistema de chat el 13 de octubre de 2026 y no lo documenta: la compatibilidad es experimental, y la protección antibots de Kick puede bloquear algunas solicitudes (Kick bloquea la solicitud). Clic derecho en la pestaña › Reconectar, o cierra y vuelve a abrir el chat. Si el error persiste, abre una incidencia con chat.log.

«Canal no encontrado» Chat

Comprueba la ortografía y la plataforma seleccionada: un nombre escrito solo va a la pastilla seleccionada. Mejor pega el enlace del canal, que selecciona la plataforma por sí solo.

El chat de Steam TV se queda vacío Chat

El chat solo existe durante una emisión. Mientras no hay emisión, Streamlink Chat vuelve a comprobarlo cada 30 segundos y muestra los mensajes en cuanto empieza.

No puedo escribir en el chat Chat

Tienes que conectar tu cuenta (consulta Escribir en el chat). Steam TV se queda en solo lectura. En Twitch, comprueba también que no estás expulsado del chat y que la sala no es solo para suscriptores.

El inicio de sesión en Kick no termina Chat
  • Comprueba que la URL de redirección de tu aplicación de Kick es exactamente http://localhost:48125/callback.
  • Comprueba el Client ID y el Client Secret (sin espacios de más).
  • El puerto 48125 debe estar libre y tu cortafuegos no debe bloquear las conexiones locales.
Tengo que volver a iniciar sesión tras cambiar de PC Chat

Es lo esperado: en Windows, los tokens se cifran para tu cuenta en este PC. Copiados a otro sitio, no se pueden leer. Vuelve a iniciar sesión en Ajustes › Cuentas.

Algunos emotes aparecen como texto Chat

Tk solo muestra PNG y GIF. Un emote que solo se ofrece en WebP o AVIF se queda como texto. Comprueba también que su proveedor (BetterTTV, FrankerFaceZ, 7TV) está activado en Ajustes › Emotes y que está disponible para esta plataforma (consulta Emotes y plataformas).

El chat usa mucha memoria Chat

Los emotes animados son lo que más consume. Desde la 0.2.1, solo se animan en el chat que se muestra y la caché está limitada. Puedes reducir aún más la memoria desactivando Emotes animados o guardando 500 mensajes por chat (Ajustes › Visualización).

La actualización integrada falla Launcher Chat

La aplicación debe poder sustituir su propio archivo: coloca el .exe en una carpeta tuya (por ejemplo Documents\Streamlink), no en C:\Program Files. Si falla, se restaura la versión anterior; siempre puedes descargar la nueva desde la página de versiones.

Un archivo de ajustes está dañado Launcher Chat

Al iniciar, la aplicación prueba su copia .bak y, en el caso del lanzador, aparta el archivo dañado como .corrupt y te avisa. Para empezar de cero, cierra la aplicación y cambia el nombre del archivo en cuestión: se volverá a crear con los ajustes por defecto.

Sin resultados. Prueba otra palabra o haz tu pregunta en GitHub.

15 · Desinstalación

Desinstalar sin dejar rastro

Las aplicaciones no instalan nada: basta con borrar sus archivos. Unas pocas precauciones evitan restos.

El lanzador en Windows Launcher

  1. Si Iniciar con Windows está activado, desactívalo primero en Ajustes › Ventana y atajo.
  2. Anota dónde están tus datos: Ajustes › Acerca de › Abrir la carpeta de datos. Si quieres conservar tus favoritos, haz un Exportar….
  3. Cierra el lanzador: clic derecho en su icono junto al reloj › Salir.
  4. Borra el .exe y después la carpeta de datos (config.json, platforms.json, streams/, launcher.log y los archivos .bak), junto al .exe o en %APPDATA%\Streamlink Launcher.

¿Ya lo borraste sin desactivar el inicio? Desactiva la entrada en el Administrador de tareas › Aplicaciones de arranque, o borra el valor StreamlinkLauncher de HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

El chat en Windows Chat

  1. En Ajustes › Cuentas, haz clic en Cerrar sesión para cada cuenta y, si quieres, revoca el acceso en Twitch o Kick (consulta Escribir en el chat).
  2. Cierra el chat.
  3. Borra el .exe, chat.json y su .bak, la carpeta cache/ y chat.log, junto al .exe o en %APPDATA%\Streamlink Chat.

En Linux Launcher Chat

Borra la AppImage y después las carpetas de datos:

$ rm -r ~/.config/streamlink-launcher ~/.config/streamlink-chat

Si creaste una entrada de menú con Gear Lever o AppImageLauncher, quítala desde esa herramienta.

¿Y Streamlink?

Se desinstala por separado, igual que lo instalaste: Configuración de Windows › Aplicaciones para el instalador, winget uninstall streamlink, pip uninstall streamlink o el gestor de paquetes de tu distribución. Su archivo de configuración está en %APPDATA%\streamlink o ~/.config/streamlink.

16 · Comunidad

Reportar un error y contribuir

Antes de abrir una incidencia

  • Actualiza la aplicación: solo la última versión recibe correcciones.
  • Busca en las incidencias existentes (Launcher, Chat): puede que el problema ya se conozca.
  • Repasa la Solución de problemas.

Qué incluir

  • La aplicación y su versión (Ajustes › Acerca de o Ajustes › Actualizaciones).
  • Tu sistema (Windows 11, Ubuntu 24.04…) y el tipo de instalación: .exe, AppImage o código fuente.
  • La versión de Streamlink: streamlink --version.
  • Qué hiciste, qué esperabas y qué pasó. En el caso de un chat, la plataforma y el canal.
  • El registro: launcher.log o chat.log (y .log.1 si existe), en la carpeta de datos. Si un stream no arranca, copia también el texto del panel de registro.

Lee el registro antes de enviarlo. Puede contener nombres de canales o rutas de tu PC; quita lo que no quieras hacer público.

Después abre una incidencia: Launcher o Chat.

¿Una vulnerabilidad de seguridad?

No abras una incidencia pública. Usa el formulario privado de GitHub (Launcher, Chat) con la versión, los pasos para reproducirla y el impacto. Recibirás respuesta en una semana aproximadamente.

Contribuir

Los informes de errores, las traducciones y las pull requests son bienvenidos.

  1. Para cualquier cosa más grande que una pequeña corrección, abre primero una incidencia para hablarlo.
  2. Solo necesitas Python 3.10 o posterior, sin dependencias de terceros. Tkinter es necesario para la interfaz.
  3. Ejecuta las comprobaciones antes de la pull request:
$ python -m unittest discover -s tests -v $ python -m pip install ruff && python -m ruff check . $ xvfb-run -a python -m unittest tests.test_gui
  • Añade una línea bajo Unreleased en CHANGELOG.md, en inglés y en francés.
  • Las versiones las publica el mantenedor.

Traducir las aplicaciones

Los textos están en lang/*.json, un archivo por idioma (fr, en, es, de, it). Todos los idiomas deben tener exactamente las mismas claves: una prueba lo comprueba. Para un idioma nuevo, copia en.json, traduce los valores sin tocar las claves ni las {variables} y mantén los textos cortos, sobre todo en el lanzador.

Formato de streaming dividido en pequeños segmentos, usado por Twitch y Kick.

Antiguo protocolo de chat sobre el que se basa el chat de Twitch.

Retraso entre lo que ocurre en el lado del emisor y lo que ves.

Mensaje que menciona tu nombre de usuario o una palabra que has elegido. Aparece resaltado.

Forma estándar de permitir que una aplicación actúe en tu nombre sin darle tu contraseña.

Archivo del lanzador que describe las plataformas: dirección, opciones, calidades, color, estado en directo.

Parte de Streamlink que sabe leer un sitio concreto (twitch, kick, steam…).

Una aplicación que guarda sus ajustes junto a su archivo: puedes moverla o copiarla a una memoria USB.

Antiguo sistema en tiempo real del chat de Kick, conservado como alternativa.

Herramienta que convierte un programa de Python en un único .exe.

Programa que muestra el vídeo enviado por Streamlink: VLC, mpv, PotPlayer…

La huella de un archivo. Si coincide con la de la versión publicada, el archivo no se ha alterado.

Protección de Windows que avisa en el primer inicio de un programa reciente o sin firma.

Un chat que puedes leer pero en el que no puedes escribir: sin cuenta conectada, o siempre en Steam TV.

Programa libre que recupera un stream y lo envía a tu reproductor. Las dos aplicaciones se basan en él.

Clave temporal que Twitch o Kick da a la aplicación después de iniciar sesión. Sustituye a tu contraseña, que la aplicación nunca ve.
