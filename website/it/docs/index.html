01 · Panoramica

Cosa sono Streamlink Launcher e Streamlink Chat?

Launcher

Un'interfaccia leggera per Streamlink. Scrivi il nome di un canale o incolla un link, premi Invio e lo stream si apre nel tuo lettore video (VLC, mpv, PotPlayer…) invece che nel browser. Ricorda i tuoi preferiti, ti dice quali sono in diretta e apre una barra mini con Ctrl+Alt+S.

Chat

Il compagno del launcher, nello spirito di Chatterino: le chat di Twitch, Kick e Steam TV in un'unica finestra, una scheda per chat, ognuna con il colore della sua piattaforma. Lettura senza account, scrittura su Twitch e Kick dopo l'accesso, e ▶ per aprire lo stream con Streamlink.

Piattaforme supportate

PiattaformaLauncherChat
TwitchSì, senza pubblicitàLettura e scrittura
KickSìLettura e scrittura (sperimentale)
Steam TVSìSola lettura
YouTube, DailymotionSìNo
Link direttoQualsiasi sito supportato da StreamlinkNo

Requisiti

  • Windows 10 o 11: un .exe in un unico file, senza installazione.
  • Linux x86_64: un'AppImage che include il proprio Python. Richiede glibc 2.35 o successiva (Ubuntu 22.04, Debian 12, Fedora 36, Linux Mint 21 o successive).
  • Dal codice sorgente: Python 3.10 o successivo con Tcl/Tk, nessun'altra dipendenza.
  • Per guardare: Streamlink e un lettore video, VLC come predefinito.

Su Linux il launcher non ha icona nell'area di notifica, scorciatoia globale, avvio con il sistema, trascinamento, notifiche delle dirette, anteprime degli stream né aggiornamento integrato.

Lingue

Le due app sono disponibili in inglese, francese, spagnolo, tedesco e italiano. Seguono la lingua del sistema; puoi cambiarla in Impostazioni › Generale (Launcher) o Impostazioni › Visualizzazione (Chat).

03 · Il motore

Che cos'è Streamlink?

Streamlink è un programma libero a riga di comando. Recupera il flusso video di uno stream e lo invia al tuo lettore. Così guardi Twitch, Kick o YouTube in VLC o mpv, senza la pagina web intorno: meno memoria, niente pubblicità di Twitch e le scorciatoie del tuo lettore.

Di solito Streamlink si usa in un terminale:

$ streamlink https://www.twitch.tv/eslcs best

Streamlink Launcher scrive questo comando al posto tuo: riconosce la piattaforma, aggiunge le opzioni giuste e la qualità scelta, poi avvia Streamlink. Streamlink Chat lo usa per il suo pulsante ▶.

Qualità

best sceglie la qualità più alta, worst la più bassa, audio_only solo l'audio (Twitch). Puoi anche chiedere una qualità precisa come 1080p60, o un elenco di riserva: 720p60,720p,best prende la prima disponibile.

E la pubblicità di Twitch?

Dalla versione 7.5.0, Streamlink filtra sempre la pubblicità degli stream di Twitch. La vecchia opzione --twitch-disable-ads non serve più (è deprecata, ma ancora accettata).

Streamlink è un progetto indipendente. Nessuna delle due app lo include: lo installi a parte, una volta sola.

04 · Installazione

Dove scaricare Streamlink e come installarlo?

Streamlink è disponibile sul suo sito ufficiale, streamlink.github.io/install. Scegli il tuo sistema:

Windows: il programma di installazione (consigliato)

  1. Apri la pagina delle versioni di Streamlink per Windows.
  2. Scarica il programma di installazione .exe dell'ultima versione (Windows 10 o successivo, x86_64).
  3. Avvialo e segui i passaggi. Aggiunge Streamlink al PATH: il launcher lo trova da solo.

Oppure con un gestore di pacchetti

# winget (incluso in Windows 11) > winget install streamlink # Chocolatey > choco install streamlink # Scoop > scoop bucket add extras > scoop install streamlink

Linux: il pacchetto della tua distribuzione

# Fedora $ sudo dnf install streamlink # Arch Linux $ sudo pacman -S streamlink # Debian testing / sid $ sudo apt update && sudo apt install streamlink

Ubuntu e derivate: il sito di Streamlink sconsiglia il pacchetto di Ubuntu, che non è mantenuto. Usa l'installazione con Python (scheda successiva) o l'AppImage di Streamlink, offerta nella stessa pagina.

Ti serve anche un lettore, per esempio sudo apt install mpv o sudo dnf install vlc.

Con Python (qualsiasi sistema)

Richiede Python 3.10 o successivo.

$ pip install -U streamlink

Lo stesso comando aggiorna Streamlink. Su Linux è meglio un ambiente virtuale o pipx install streamlink, per non toccare il Python di sistema.

Verificare l'installazione

$ streamlink --version

Se il comando mostra un numero di versione, è tutto pronto. Nel Launcher, Impostazioni › Streamlink mostra anche la versione trovata.

Streamlink installato altrove? Launcher Chat

Le app cercano Streamlink nel PATH e nelle posizioni abituali. Se si trova altrove, indica il percorso di streamlink.exe in Impostazioni › Streamlink › Percorso personalizzato (Launcher) o in Impostazioni › Guarda (Chat).

05 · Si comincia

Primi passi

Dove mettere le app Launcher Chat

Scarica il file dalla pagina delle versioni (Launcher, Chat) e mettilo in una cartella tua, per esempio Documents\Streamlink. Le impostazioni vengono salvate accanto e l'aggiornamento integrato può sostituire il file. Evita C:\Program Files, che è protetta da scrittura.

Su Linux, rendi eseguibile l'AppImage, poi avviala:

$ chmod +x StreamlinkLauncher-*-x86_64.AppImage $ ./StreamlinkLauncher-*-x86_64.AppImage

Per avere una voce nel menu delle applicazioni, usa uno strumento come Gear Lever o AppImageLauncher.

Il tuo primo stream Launcher

  1. Assicurati che Streamlink e un lettore video siano installati.
  2. Scegli la piattaforma con il suo pulsante: Twitch, Kick, YouTube, Dailymotion, Steam TV o Link diretto.
  3. Scrivi il nome del canale (eslcs) o incolla un link (https://kick.com/…): un link seleziona la piattaforma da solo.
  4. Scegli la qualità se serve, poi Invio o Avvia. Il lettore si apre dopo qualche secondo.
  5. Per seguire o fermare lo stream, apri il Registro in fondo alla finestra: mostra l'output di Streamlink e un pulsante Interrompi.

Tre modi più rapidi Launcher

  • Copiare un link: copia l'indirizzo di uno stream, poi torna al launcher. Ti propone di avviarlo, e il link è già nella barra mini. Si può disattivare in Impostazioni › Streamlink › Rileva i link copiati.
  • Trascinare e rilasciare (Windows): trascina sulla finestra l'indirizzo dalla barra del browser, un testo selezionato o un collegamento Internet .url.
  • Modalità mini (Windows): Ctrl+Alt+S da qualsiasi applicazione, scrivi, Invio.

La tua prima chat Chat

  1. Scegli la piattaforma con il suo pulsante, sotto il campo Aggiungi una chat.
  2. Scrivi il nome del canale o incolla un link, poi Invio. Ctrl+T porta il cursore in questo campo.
  3. La chat si apre in una nuova scheda, in sola lettura. Per scrivere, collega il tuo account (vedi Scrivere in chat).
  4. Nell'intestazione della chat, ▶ apre lo stream con Streamlink e l'icona del link apre il canale nel browser.

Il campo accetta un nome (eslcs), un prefisso (kick:lunaria, steam:nome) o un link: twitch.tv/…, kick.com/…, steam.tv/…, steamcommunity.com/broadcast/watch/…, link «popout» compresi. Le tue schede tornano al prossimo avvio.

07 · Ogni giorno

Come gestisco cronologia e preferiti?

Aggiungere un preferito Launcher

  1. Scegli la piattaforma con il suo pulsante (Twitch, Kick…) e scrivi il nome del canale.
  2. Fai clic sulla scheda Aggiungi ai preferiti nella schermata principale.

La schermata principale mostra i preferiti della piattaforma selezionata, prima quelli in diretta. Mostra tutto apre l'elenco completo.

Avviare, modificare o rimuovere un preferito Launcher

  • Avviare: fai clic sulla sua scheda.
  • Altre opzioni: clic destro sulla scheda, poi Avvia, Compila il campo o Rimuovi dai preferiti.
  • Nel pannello Preferiti: un clic su una riga compila il campo, ▶ avvia, il cestino rimuove.

Chi è in diretta? Launcher

Con Impostazioni › In diretta › Controlla chi è in diretta, il launcher controlla i tuoi preferiti di Twitch e Kick finché è aperto, ogni 2, 5, 10, 15 o 30 minuti (5 come predefinito). Anteprima delle dirette aggiunge miniatura, titolo e numero di spettatori dei preferiti Twitch in diretta, e Notifica di Windows ti avvisa quando un preferito va in diretta: fai clic sulla notifica per guardarlo.

Cronologia Launcher

  • Vengono conservati gli ultimi 200 avvii. I più recenti compaiono in Recenti; ▶ li riavvia direttamente.
  • Cronologia completa apre il pannello: un clic compila il campo, ▶ riavvia, il cestino elimina una voce, Cancella tutto svuota la cronologia.
  • I suggerimenti del campo di inserimento vengono dai tuoi preferiti, poi dalla cronologia: usa ↓ ↑, poi Invio.

Fare un backup o passare a un altro PC Launcher

Impostazioni › Backup › Esporta… salva impostazioni e preferiti in un unico file. Importa… li ripristina e ti lascia scegliere: Sì aggiunge i preferiti importati ai tuoi, No sostituisce i tuoi preferiti, Annulla non cambia nulla. I percorsi specifici del computer (Streamlink, lettore, script) non sono inclusi, e nemmeno la cronologia.

E nella chat? Chat

Streamlink Chat non ha preferiti: le chat aperte tornano da sole al prossimo avvio. Chiudi una chat con Ctrl+W o con un clic centrale sulla sua scheda. Per aprire sempre le stesse chat in un colpo solo, vedi la ricetta Aprire le tue chat da un collegamento.

08 · Account

Scrivere in chat

Per leggere non serve un account. Per scrivere ti serve una tua applicazione gratuita su ogni piattaforma: così nessun segreto viene distribuito con il programma. Lo fai una volta sola.

Collegare Twitch Chat

  1. Apri dev.twitch.tv/console/apps/create e accedi con il tuo account Twitch. Twitch potrebbe chiederti di attivare l'autenticazione a due fattori per usare la console.
  2. Dai un nome all'applicazione, aggiungi l'URL di reindirizzamento http://localhost, scegli la categoria Chat Bot e il tipo di client Public, poi creala.
  3. Copia il suo Client ID e incollalo in Impostazioni › Account (per scrivere).
  4. Fai clic su Accedi a Twitch. Si apre una pagina twitch.tv/activate: inserisci il codice mostrato dall'app e autorizzala.
  5. L'intestazione delle chat di Twitch passa a Connesso. La connessione si rinnova da sola.

L'app chiede solo due autorizzazioni: leggere e scrivere in chat (chat:read, chat:edit).

Collegare Kick Chat

  1. Apri le impostazioni sviluppatore di Kick e crea un'applicazione.
  2. Dichiara l'URL di reindirizzamento http://localhost:48125/callback e spunta i permessi read user info e write to chat.
  3. Incolla il suo Client ID e il suo Client Secret in Impostazioni › Account (per scrivere).
  4. Fai clic su Accedi a Kick: il browser si apre su Kick, autorizza l'applicazione. Kick ti rimanda a localhost:48125, dove l'app attende la risposta.

La porta 48125 deve essere libera durante l'accesso. Se un altro programma la usa, chiudilo mentre ti colleghi.

Steam TV Chat

Steam non permette di scrivere nella chat di una trasmissione da un altro programma: Steam TV resta in sola lettura, senza account.

Dove vengono conservati i token? Chat

  • In chat.json. Su Windows sono cifrati con DPAPI: solo il tuo account Windows, su questo PC, può rileggerli.
  • Su Linux sono salvati in chiaro nella tua cartella personale. Non condividere questo file.
  • Se copi chat.json su un altro PC, lì i token non potranno essere letti: accedi di nuovo.

Disconnettersi e revocare l'accesso Chat

  • Disconnetti, in Impostazioni › Account, elimina i token dal tuo PC.
  • Per revocare l'accesso anche dal lato di Twitch, apri Impostazioni › Connessioni su Twitch e scollega la tua applicazione.
  • Dal lato di Kick, elimina l'applicazione nelle impostazioni sviluppatore.

10 · Ricette

Ricette per fare prima

Scegliere il lettore del pulsante ▶ Chat

La chat avvia Streamlink senza alcuna opzione per il lettore, quindi Streamlink usa quello del suo file di configurazione, VLC come predefinito. Per passare a mpv, crea questo file (senza estensione) e aggiungi:

configplayer=mpv player-args=--force-window=immediate
SistemaFile di configurazione di Streamlink
Windows%APPDATA%\streamlink\config
Linux~/.config/streamlink/config

Se mpv non è nel PATH, metti il suo percorso completo dopo player=. Il Launcher usa questo file anche quando Impostazioni › Lettore video è su Predefinito (impostazione di Streamlink).

Guardare con meno ritardo

Streamlink ha una modalità a bassa latenza per Twitch e Kick. Il modo più semplice è attivarla per una sola piattaforma, con un file di configurazione per il suo plugin, accanto al file config:

config.twitchtwitch-low-latency
config.kickkick-low-latency

Funziona con entrambe le app. Il guadagno dipende dallo streamer, che deve aver attivato la bassa latenza; la riproduzione potrebbe andare in buffering un po' più spesso.

Registrare uno stream mentre lo guardi

In un terminale, --record scrive lo stream in un file mentre lo guardi:

$ streamlink --record "{author}-{time:%Y%m%d-%H%M}.ts" https://www.twitch.tv/eslcs best

{author} diventa il nome del canale e {time:…} la data e l'ora. Apri il file .ts con VLC o mpv.

Launcher Per farlo dal launcher, aggiungi una piattaforma dedicata in platforms.json (il link Modifica platforms.json in fondo alle impostazioni), con un percorso completo verso la tua cartella dei video:

platforms.json (una voce in più nell'elenco "platforms"){ "id": "twitch-rec", "name": "Twitch REC", "input": "channel", "url": "https://www.twitch.tv/{arg}", "hosts": [], "args": ["--record", "C:\\Users\\tu\\Videos\\{author}-{time:%Y%m%d-%H%M}.ts"], "qualities": ["best", "1080p60", "720p60", "480p"], "color": "#E91916", "text_color": "#FFFFFF", "live_check": "none" }

Riavvia il launcher: compare un pulsante Twitch REC. hosts resta vuoto perché i link di Twitch incollati continuino ad andare al normale pulsante Twitch. In JSON, ogni \ di un percorso Windows si scrive \\.

Mai più «qualità non trovata»

Non tutti i canali offrono tutte le qualità. Launcher Nell'elenco delle qualità, scegli Personalizzata… e inserisci un elenco di riserva come 720p60,720p,best: Streamlink prende la prima che esiste e il launcher la ricorda per questa piattaforma. Chat La qualità del pulsante ▶ si sceglie da un elenco fisso; tieni best se guardi canali molto diversi.

Aprire le tue chat da un collegamento Chat

Streamlink Chat accetta le chat come argomenti. Crea un collegamento di Windows (clic destro sul desktop › Nuovo › Collegamento) con una destinazione come:

"C:\Users\tu\Documents\Streamlink\StreamlinkChat.exe" --open twitch:eslcs --open kick:lunaria

Se la chat è già aperta, queste chat vengono aggiunte alla finestra esistente. Anche un link di canale funziona come argomento.

Suggerimento: prima rinomina l'eseguibile senza numero di versione, per esempio StreamlinkChat.exe. Un file che porta la sua versione nel nome cambia nome a ogni aggiornamento e il collegamento non lo troverebbe più. Un nome senza versione viene mantenuto.

Avviare il launcher ridotto a icona Launcher

Impostazioni › Finestra e scorciatoia › Avvia con Windows lo avvia nell'area di notifica. Puoi fare lo stesso con un tuo collegamento aggiungendo --tray dopo il percorso dell'eseguibile.

Tenere i tuoi vecchi script .bat Launcher

Se prima avviavi gli stream con degli script, attiva Impostazioni › Avanzate › Mostra gli script .bat e scegli la Cartella degli script. Un pulsante Script elenca i file .bat, .cmd, .ps1, .exe, .py e .lnk di quella cartella. Il campo permette di passare un argomento allo script (solo lettere, cifre, ., _ e -).

11 · Aggiornamenti

Come aggiorno l'app?

Il launcher Launcher

  1. Apri Impostazioni › Informazioni: la scheda mostra la tua versione e l'ultima pubblicata su GitHub.
  2. Se esiste una versione più recente, fai clic su Aggiorna. Il launcher scarica il nuovo .exe, ne verifica dimensione e impronta SHA-256, lo mette al posto del vecchio e si riavvia.
  • Cerca aggiornamenti all'avvio fa il controllo da solo.
  • Aggiorna il launcher automaticamente installa anche la nuova versione all'avvio, mai durante uno stream.
  • Un file che porta la sua versione nel nome (StreamlinkLauncher-1.4.2.exe) prende il nuovo numero; l'avvio con Windows segue il nuovo nome.

La chat Chat

Stessa idea in Impostazioni › Aggiornamenti: Verifica, poi Aggiorna. La chat si riavvia con le tue chat aperte. Un punto sul pulsante delle impostazioni segnala una nuova versione, e Aggiornamenti automatici (disattivato come predefinito) fa tutto da solo all'avvio.

AppImage o codice sorgente: l'aggiornamento con un clic vale solo per il .exe di Windows messo in una cartella scrivibile (non C:\Program Files). Con l'AppImage, Aggiorna apre la pagina della versione: scarica la nuova AppImage e sostituisci la vecchia. Dal codice sorgente, esegui git pull.

Aggiornare Streamlink stesso

Il launcher confronta la tua versione di Streamlink con l'ultima pubblicata. Se la tua è più vecchia, la scheda Impostazioni › Streamlink propone Aggiorna: con il programma di installazione di Windows apre la pagina di download, con pip copia il comando pip install -U streamlink. Con winget, Chocolatey, Scoop o la tua distribuzione Linux, usa il loro solito comando di aggiornamento (winget upgrade streamlink, per esempio).

12 · Impostazioni

Altre domande sulle impostazioni

Come scelgo il lettore video? Launcher

Impostazioni › Lettore video: scegli VLC, mpv, PotPlayer o un altro programma e indica il suo percorso se non viene trovato. Argomenti del lettore aggiunge opzioni, per esempio --fullscreen. Predefinito (impostazione di Streamlink) lascia decidere a Streamlink (vedi la ricetta).

Come cambio la qualità predefinita? Launcher Chat

Nel launcher, l'elenco accanto al campo ricorda la qualità per piattaforma; Personalizzata… accetta una qualità precisa o un elenco di riserva. Nella chat è Impostazioni › Guarda › Qualità, usata dal pulsante ▶.

Come cambio la scorciatoia della modalità mini? Launcher

Impostazioni › Finestra e scorciatoia: attiva o disattiva Scorciatoia globale e scegli una combinazione diversa da Ctrl+Alt+S. Lì viene mostrato anche lo stato della scorciatoia.

Il launcher può restare attivo in background? Launcher

Sì: con Riduci a icona nell'area di notifica, chiudere la finestra lascia il launcher accanto all'orologio, con i tuoi stream e il controllo delle dirette. Clic destro sull'icona per riaprire la finestra, aprire la modalità mini, avviare un preferito in diretta o Esci. Avvia con Windows lo avvia ridotto a icona.

Come disattivo il rilevamento dei link copiati? Launcher

Togli la spunta da Rileva i link copiati in Impostazioni › Streamlink. Gli appunti vengono letti solo sul tuo computer; nulla viene salvato o inviato.

Posso togliere i colori delle piattaforme? Launcher Chat

Sì: Colori per piattaforma in Impostazioni › Generale (Launcher) o Impostazioni › Visualizzazione (Chat).

Come aggiungo una piattaforma? Launcher

Il link Modifica platforms.json, in fondo al pannello delle impostazioni, apre il file. Ogni voce indica:

  • id e name: un identificatore unico e il nome del pulsante;
  • input: channel, youtube, video, url (qualsiasi link) o none (niente da scrivere);
  • url: il modello dell'indirizzo, dove {arg} viene sostituito da ciò che scrivi;
  • hosts: i domini che selezionano questo pulsante quando incolli un link;
  • args: opzioni aggiuntive di Streamlink;
  • qualities, color, text_color;
  • live_check: twitch, streamlink o none.

Salva, poi riavvia il launcher per vedere il nuovo pulsante. Un esempio completo si trova nella ricetta Registrare uno stream.

Come scrivo in una chat? Chat

Collega il tuo account Twitch o Kick in Impostazioni › Account (per scrivere). I passaggi sono spiegati in Scrivere in chat.

Quali opzioni di visualizzazione offre la chat? Chat

Impostazioni › Visualizzazione: lingua, tema, dimensione del testo, ora dei messaggi, badge, emote animate, colori per piattaforma e numero di messaggi conservati per chat (500, 1000, 2000 o 5000). Emote attiva o disattiva BetterTTV, FrankerFaceZ e 7TV. Menzioni evidenzia i messaggi che citano il tuo nome o parole a tua scelta, separate da virgole.

14 · Risoluzione dei problemi

Risoluzione dei problemi (FAQ)

«Streamlink non trovato» Launcher Chat

Installa Streamlink (vedi Installare Streamlink), poi riavvia l'app. Se è installato altrove, indica il percorso di streamlink.exe nelle impostazioni. Verifica in un terminale che streamlink --version risponda.

Lo stream non parte Launcher

Apri il pannello del registro in fondo alla finestra: lì compare il messaggio di errore di Streamlink. Le cause più comuni:

  • No playable streams found: il canale è offline, o il nome è scritto male.
  • La qualità richiesta non esiste per questo stream: scegli best o un elenco di riserva con Personalizzata….
  • Il lettore video non viene trovato: indica il suo percorso in Impostazioni › Lettore video.
Lo stream scatta o si interrompe Launcher Chat

Prova una qualità più bassa (720p, 480p): richiede meno banda. Se hai attivato la bassa latenza, toglila. I messaggi del registro dicono se Streamlink sta aspettando dati.

C'è l'audio, ma non il video Launcher

Verifica che la qualità scelta non sia audio_only. Altrimenti aggiorna il lettore; con mpv, l'opzione --force-window=immediate apre subito la finestra.

Windows mostra «Windows ha protetto il PC» Launcher Chat

Gli eseguibili non hanno ancora una firma del codice, quindi SmartScreen avvisa al primo avvio. Non è un rilevamento.

  1. Verifica il file: in PowerShell, Get-FileHash .\StreamlinkLauncher-1.5.1.exe, e confronta con il SHA256SUMS.txt della versione.
  2. Fai clic su Ulteriori informazioni, poi su Esegui comunque.
  3. Se con il doppio clic non succede nulla: clic destro › Proprietà › spunta Annulla blocco, oppure Unblock-File .\StreamlinkLauncher-1.5.1.exe.
Il mio antivirus blocca o elimina l'exe Launcher Chat

I programmi creati con PyInstaller vengono talvolta segnalati per errore. Verifica lo SHA-256, ripristina il file dalla quarantena, aggiungi la sua cartella alle esclusioni e segnala il falso positivo (Microsoft Defender: invia un file, categoria Incorrectly detected as malware). Puoi anche avviare l'app dal codice sorgente.

Ctrl+Alt+S non fa nulla Launcher

Probabilmente un'altra applicazione usa questa scorciatoia. Il launcher ti avvisa all'avvio; scegline un'altra in Impostazioni › Finestra e scorciatoia. Ogni pressione ricevuta viene annotata nel registro. La scorciatoia globale esiste solo su Windows.

L'app non si apre una seconda volta Launcher Chat

È voluto: di ogni app gira una sola copia alla volta. Il launcher è probabilmente nell'area di notifica, accanto all'orologio. Per la chat, riaprirla invia le sue chat alla finestra già aperta.

«La cartella del launcher è protetta da scrittura» Launcher

Il launcher non può scrivere accanto al suo .exe (per esempio in C:\Program Files). Salva allora i suoi dati in %APPDATA%\Streamlink Launcher. Tutto funziona, ma l'aggiornamento integrato non potrà sostituire il file: spostalo in una cartella tua.

L'AppImage non si avvia Launcher Chat
  • Rendila eseguibile: chmod +x seguito dal nome del file.
  • Messaggio su FUSE: installa libfuse2, oppure avviala con --appimage-extract-and-run.
  • Errore su GLIBC: il tuo sistema è troppo vecchio (glibc 2.35 come minimo). Avvia l'app dal codice sorgente.
Una chat di Kick resta in errore Chat

Kick ha cambiato il suo sistema di chat il 13 ottobre 2026 e non lo documenta: il supporto è sperimentale, e la protezione anti-bot di Kick può bloccare alcune richieste (Kick blocca la richiesta). Clic destro sulla scheda › Riconnetti, oppure chiudi e riapri la chat. Se l'errore persiste, apri una segnalazione con chat.log.

«Canale non trovato» Chat

Controlla l'ortografia e la piattaforma selezionata: un nome scritto da solo va al pulsante selezionato. Incolla piuttosto il link del canale, che seleziona la piattaforma da solo.

La chat di Steam TV resta vuota Chat

La chat esiste solo durante una trasmissione. Finché è offline, Streamlink Chat ricontrolla ogni 30 secondi e mostra i messaggi appena inizia la trasmissione.

Non riesco a scrivere in chat Chat

Devi collegare il tuo account (vedi Scrivere in chat). Steam TV resta in sola lettura. Su Twitch, verifica anche di non essere bannato dalla chat e che la stanza non sia riservata agli abbonati.

L'accesso a Kick non si completa Chat
  • Verifica che l'URL di reindirizzamento della tua applicazione Kick sia esattamente http://localhost:48125/callback.
  • Verifica Client ID e Client Secret (senza spazi in più).
  • La porta 48125 deve essere libera e il firewall non deve bloccare le connessioni locali.
Devo accedere di nuovo dopo aver cambiato PC Chat

È normale: su Windows i token sono cifrati per il tuo account su questo PC. Copiati altrove, non possono essere letti. Accedi di nuovo in Impostazioni › Account.

Alcune emote compaiono come testo Chat

Tk mostra solo PNG e GIF. Un'emote offerta solo in WebP o AVIF resta come testo. Verifica anche che il suo fornitore (BetterTTV, FrankerFaceZ, 7TV) sia attivo in Impostazioni › Emote e che sia disponibile per questa piattaforma (vedi Emote e piattaforme).

La chat usa molta memoria Chat

Le emote animate sono le più pesanti. Dalla 0.2.1 si animano solo nella chat visualizzata e la cache è limitata. Puoi ridurre ancora la memoria disattivando Emote animate o conservando 500 messaggi per chat (Impostazioni › Visualizzazione).

L'aggiornamento integrato non riesce Launcher Chat

L'app deve poter sostituire il proprio file: metti il .exe in una cartella tua (per esempio Documents\Streamlink), non in C:\Program Files. In caso di errore viene ripristinata la vecchia versione; puoi sempre scaricare la nuova dalla pagina delle versioni.

Un file di impostazioni è danneggiato Launcher Chat

All'avvio l'app prova la sua copia .bak e, per il launcher, mette da parte il file danneggiato come .corrupt e ti avvisa. Per ripartire da zero, chiudi l'app e rinomina il file in questione: verrà ricreato con le impostazioni predefinite.

Nessun risultato. Prova un'altra parola o fai la tua domanda su GitHub.

15 · Disinstallazione

Disinstallare senza lasciare tracce

Le app non installano nulla: basta eliminare i loro file. Qualche precauzione evita residui.

Il launcher su Windows Launcher

  1. Se Avvia con Windows è attivo, disattivalo prima in Impostazioni › Finestra e scorciatoia.
  2. Annota dove sono i tuoi dati: Impostazioni › Informazioni › Apri la cartella dei dati. Se vuoi tenere i preferiti, fai un Esporta….
  3. Chiudi il launcher: clic destro sulla sua icona accanto all'orologio › Esci.
  4. Elimina il .exe, poi la cartella dei dati (config.json, platforms.json, streams/, launcher.log e i file .bak), accanto al .exe o in %APPDATA%\Streamlink Launcher.

Già eliminato senza disattivare l'avvio? Disattiva la voce in Gestione attività › App di avvio, oppure elimina il valore StreamlinkLauncher da HKCU\Software\Microsoft\Windows\CurrentVersion\Run.

La chat su Windows Chat

  1. In Impostazioni › Account, fai clic su Disconnetti per ogni account, poi revoca l'accesso dal lato di Twitch o Kick se vuoi (vedi Scrivere in chat).
  2. Chiudi la chat.
  3. Elimina il .exe, chat.json e il suo .bak, la cartella cache/ e chat.log, accanto al .exe o in %APPDATA%\Streamlink Chat.

Su Linux Launcher Chat

Elimina l'AppImage, poi le cartelle dei dati:

$ rm -r ~/.config/streamlink-launcher ~/.config/streamlink-chat

Se hai creato una voce di menu con Gear Lever o AppImageLauncher, rimuovila da quello strumento.

E Streamlink?

Si disinstalla a parte, nello stesso modo in cui l'hai installato: Impostazioni di Windows › App per il programma di installazione, winget uninstall streamlink, pip uninstall streamlink o il gestore di pacchetti della tua distribuzione. Il suo file di configurazione si trova in %APPDATA%\streamlink o ~/.config/streamlink.

16 · Comunità

Segnalare un bug e contribuire

Prima di aprire una segnalazione

  • Aggiorna l'app: solo l'ultima versione riceve correzioni.
  • Cerca tra le segnalazioni esistenti (Launcher, Chat): il problema potrebbe essere già noto.
  • Rileggi la Risoluzione dei problemi.

Cosa includere

  • L'app e la sua versione (Impostazioni › Informazioni o Impostazioni › Aggiornamenti).
  • Il tuo sistema (Windows 11, Ubuntu 24.04…) e il tipo di installazione: .exe, AppImage o codice sorgente.
  • La versione di Streamlink: streamlink --version.
  • Cosa hai fatto, cosa ti aspettavi e cosa è successo. Per una chat, la piattaforma e il canale.
  • Il log: launcher.log o chat.log (e .log.1 se esiste), nella cartella dei dati. Per uno stream che non parte, copia anche il testo del pannello del registro.

Leggi il log prima di inviarlo. Può contenere nomi di canali o percorsi del tuo PC; togli tutto ciò che non vuoi rendere pubblico.

Poi apri una segnalazione: Launcher o Chat.

Una vulnerabilità di sicurezza?

Non aprire una segnalazione pubblica. Usa il modulo privato di GitHub (Launcher, Chat) con la versione, i passaggi per riprodurla e l'impatto. Riceverai una risposta entro una settimana circa.

Contribuire

Segnalazioni di bug, traduzioni e pull request sono benvenute.

  1. Per qualsiasi cosa più grande di una piccola correzione, apri prima una segnalazione per parlarne.
  2. Ti basta Python 3.10 o successivo, senza dipendenze di terze parti. Tkinter è necessario per l'interfaccia.
  3. Esegui i controlli prima della pull request:
$ python -m unittest discover -s tests -v $ python -m pip install ruff && python -m ruff check . $ xvfb-run -a python -m unittest tests.test_gui
  • Aggiungi una riga sotto Unreleased in CHANGELOG.md, in inglese e in francese.
  • Le versioni vengono pubblicate dal manutentore.

Tradurre le app

I testi si trovano in lang/*.json, un file per lingua (fr, en, es, de, it). Ogni lingua deve avere esattamente le stesse chiavi: un test lo verifica. Per una nuova lingua, copia en.json, traduci i valori senza toccare le chiavi né le {variabili} e tieni i testi brevi, soprattutto nel launcher.
